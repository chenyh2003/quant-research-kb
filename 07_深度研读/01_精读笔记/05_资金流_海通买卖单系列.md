# 精读 05：海通买卖单/大单/主买系列

> 研报：[P0261] 买卖单数据中的 Alpha（2019-11-07）；[P0263] 基于主动买入行为的选股因子（2020-01-12）；[P0264] 知情交易与主买主卖（2020-02-14）；[P0268] 寻找逐笔交易中的有效信息（2020-06-21）；[P0272] 大单的精细化处理与大单因子重构（2021-01-20）；[P0277] 买卖单主动成交中的隐藏信息（2022-10-24）
> 主题：资金流与大单、高频量价、订单流
> 评级：**A-（体系完整、逻辑清楚）/ B+（部分因子绩效偏高）**

---

## 1. 研究问题

- 逐笔成交中的“叫买/叫卖序号”能否把“笔”合成“单”，从而识别大单？
- 大单成交金额占比、集中度、主买占比/强度、知情主买/主卖，是否有选股能力？
- 大单阈值怎么定？固定金额还是自适应？

---

## 2. 数据与样本

- 数据：逐笔成交（叫买/叫卖序号、BS 标志）；Wind。
- 样本：全 A；区间约 2013-2022（各篇不同）。
- 频率：逐笔 → 分钟/日频 → 月度。
- 中性化：行业、市值、中盘、换手、反转、波动、估值、盈利、成长。

---

## 3. 方法与公式

### 3.1 从“笔”到“单”（P0261）
- 用逐笔成交的“叫买序号/叫卖序号”把同一订单的多笔成交合并为“买卖单”。
- 大单筛选：基于买卖单成交量的标准差，取 `均值 + N×标准差` 为阈值（N=1/3）。
- 因子：
  - 大买成交金额占比 = 大买单成交额 / 总成交额
  - 大买-大卖成交金额占比差值
  - 买单集中度、卖单集中度

### 3.2 主买占比/强度（P0263）
- 用 BS 标志区分主动买入/卖出；降频合成分钟主买/主卖金额。
- 主买占比 = 主买金额 / 总成交额；主买强度 = 均值/标准差。
- 分全天、开盘后、盘中、收盘前四个时段。

### 3.3 知情交易过滤（P0264）
- 用知情交易概率模型（PIN/VPIN 类）过滤主买/主卖，得到知情主买/主卖。
- 构造知情主卖占比、知情主买占比、知情净主买占比。

### 3.4 大单精细化（P0272）
- 原始“N 倍标准差”受买卖单分布偏度影响；先对买卖单金额做对数调整，再算阈值。
- 用滚动多日成交分布计算阈值；阈值 N 在 0-1 之间较稳健。
- 因子：大单买入占比、大单净买入占比、大单买入强度、大单净买入强度；分全天/开盘后 30 分钟。

### 3.5 主动成交度（P0277）
- 买单/卖单并非完全主动；计算大/中/小单的主动成交度。
- 小买单主动成交度因子月均 IC 0.05、月度多空 1.78%、多头超额 0.80%。

## 5. 证据强度

**加分项**：
- 从“笔”到“单”的数据处理有创新，解决了逐笔数据的订单聚合问题；
- 因子定义清楚，参数（N、时段）有对比；
- 正交前后都报告，诚实展示衰减；
- 分股票池（全 A/沪深 300/中证 500/中证 800）测试；
- 分年度测试，承认 2018 年表现较差。

**减分项/红旗**：
1. **成本缺失**：月度调仓、逐笔数据，换手不低；未给手续费/滑点。
2. **容量缺失**：全 A 等权；大单因子在小市值/低流动性股票上更强，容量有限。
3. **大单阈值敏感**：N=1 vs N=3 差异大（P0261：多空 >1% vs <1%）；P0272 用对数调整/滚动窗口改进，但仍需样本外验证。
4. **“大单=机构”假设**：大单可能是对倒/游资；P0264 用知情交易过滤是改进，但模型假设强。
5. **绩效偏高**：大买占比多空 22.7%、大单净买入月多空 1.3-1.8%、ICIR >3.5；扣成本后可能明显下降。
6. **数据依赖**：逐笔成交的“叫买/叫卖序号”在沪深覆盖/字段上有差异；未充分讨论。

## 6. 与同类研究对比

- 开源 P0203/P0207/P0209 从“大小单资金流/重定标/残差”角度改进，绩效更高但更可疑；海通系列更稳健、更注重正交。
- 东方 P0043/P0044 从“订单金额分位/超大单冲击”角度，解决深交所覆盖问题。
- 长江 P0360 提醒：小单流入额 IC -9.9%，但正交后仅 -3.62%，资金流因子容易成为流动性代理。

## 8. 我的判断

- **最可信的因子**：大买占比、主买占比、大单净买入占比。它们有明确的经济逻辑（大资金/主动买入→未来收益），正交后仍有增量。
- **最需要警惕的因子**：大单净买入强度（ICIR >3.5、月胜率 >90%），绩效高得可疑；可能是小市值/低流动性驱动。
- **“大单”不是万能**：大单可能是对倒、游资、拆单；必须结合主动成交度/知情交易/异动股过滤。
- **资金流因子的本质是“交易者结构”**：不是“钱多就涨”，而是“谁在买、为什么买、是否知情”。
