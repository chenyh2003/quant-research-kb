> 注意：这是**关键词法**的粗筛，不是对研报质量的最终判决；用于排序和发现系统性缺口。

## 一、总体统计

| 指标 | 结果 |
|---|---|
| 研报数 | 376 |
| 平均分（0-10） | 5.95 |
| 7 分以上 | 179 篇（47.6%） |
| 5 分以下 | 56 篇（14.9%） |
| 10 分 | 1 篇（P0101 华泰 GNN） |
| 0 分 | 5 篇（因子日历/外文理论/无结构化证据） |

### 关键缺口

| 缺口 | 篇数 | 占比 |
|---|---:|---:|
| 未讨论容量 | 354 | 94.1% |
| 无样本外 | 274 | 72.9% |
| 无成本假设 | 243 | 64.6% |
| 无稳健性检验 | 190 | 50.5% |
| 未做正交/中性化 | 158 | 42.0% |
| 疑似全样本寻优 | 76 | 20.2% |
| 无股票池 | 49 | 13.0% |
| 无数据源 | 15 | 4.0% |
| 无样本期 | 5 | 1.3% |

**解读**：
- **容量几乎无人讨论**：这是卖方研报的通病——全 A 等权多空好看，但资金容量有限。
- **七成无样本外**：分年度不等于样本外；研报发布后的数据才是真样本外。
- **六成无成本**：高频/周频因子扣费后可能腰斩。
- **两成疑似全样本寻优**：参数/阈值在全样本上选最优，再用同一样本回测。

## 四、按主题的缺口

| 主题 | 主要问题 |
|---|---|
| 高频量价 | 成本/容量缺失最严重；样本期多在 2020 前 |
| 订单流 | 数据覆盖（沪深/逐笔委托）与成本缺失 |
| 资金流/大单 | 大单阈值寻优、容量有限、绩效偏高 |
| 机器学习 | 随机种子/数据泄漏/样本外不足 |
| 多因子/测试 | 方法论较好，但样本期早、成本缺失 |
| 行业轮动 | 参数主观、换手高、基准不统一 |
| 文本 | 数据覆盖偏差、成本/容量、BERT 准确率过高 |
| 波动率 | 分解清楚，但成本/样本外不足 |

## 五、可疑点清单（需优先复核）

### 5.1 绩效异常（C 级）
- P0209 开源 大小单综合：多空 35.36%、IR 4.82、回撤 2.09%、胜率 89.19%。
- P0207 开源 NIR_MOD：多空 32.16%、IR 4.61、回撤 3.28%。
- P0184 国金 斜率凸性：多空 32.75%、夏普 4.13、回撤 6.89%。
- P0057 中信建投 MPC5：多空 30.63%、夏普 2.88。
- P0119 华泰 周频 XGBoost：年化超额 21.02%、IR 3.86、回撤 3.98%（换手 23.91 倍）。
- P0009 华泰 FADT：年化 44.13%、夏普 1.48、换手 16 倍。

**复核方法**：PBO + 时序 CV + 扣成本 + 分股票池 + 独立样本外。

### 5.2 口径混用
- P0055/P0056/P0057 的“IR”与“夏普”混用。
- P0063 光大“IR -0.83”与“多空夏普 3.03”差异大。
- P0083 华泰“IC_IR 0.42”未说明是否年化。

### 5.3 数据/样本
- P0022/P0274 逐笔委托覆盖（上交所 2021.5 后才完整）。
- 多篇“全 A”未处理退市/停牌/涨跌停。
- 多篇未说明财务数据 PIT。

### 5.4 归属/版本
- W 式切割：东吴 P0021（2018-12-13）首发，开源 P0211（2019-12-23）称“我们提出”；需核对引用。
- 东吴求索动量（四）2021 vs 2023 两个版本（P0033/P0038）。
- 35 组近重复；引用时优先主记录。

## 七、一句话结论

**全库的方法论比单因子数字更值钱；先学“怎么测/怎么防坑”，再复现“哪个因子”。** 第一批复现应选公式简单、逻辑清楚、正交后仍有增量的因子（W 式切割、CPV/RPV、量稳换手、大买/主买），而不是绩效最高的因子。
