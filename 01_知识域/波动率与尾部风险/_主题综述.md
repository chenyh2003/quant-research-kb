# 波动率与尾部风险 · 主题综述

> 覆盖 32 篇研报｜核心机构：海通证券、方正证券、广发证券、东吴证券、长江证券
> 关联知识域：高频量价因子、多因子框架与测试、市场微观结构理论

---

## 1. 这个领域在解决什么问题

波动率既是风险度量，也是 alpha 来源。核心问题：

1. 波动率因子为什么有效？（低波异象、彩票偏好、模糊性厌恶）
2. 如何分解波动率？（系统/特质、连续/跳跃、上行/下行）
3. 高频波动率包含什么信息？（已实现波动、信息分布、振幅）
4. 尾部风险如何度量与定价？（跳跃、重尾、极端收益）

---

## 2. 方法谱系

### 2.1 已实现波动分解（海通 25，P0254）
- 把高频波动率拆成系统波动 + 特质波动。
- 结论：两者都有选股效果；单纯高频方差/峰度不显著，拆分后显著。

### 2.2 高频偏度与下行波动占比（海通 19，P0253）
- 高频偏度、上下行波动率、下行波动占比。
- 结论：高频偏度与下行波动占比有显著选股能力。

### 2.3 信息分布均匀度（东吴波动率 2，P0026）
- 波动率与信息流：信息均匀流入 → 波动小；信息集中冲击 → 波动大。
- 构造"信息分布均匀度"因子。

### 2.4 特异波动率（长江 11，P0362）
- 特异波动率 = 波动率 + 特异率信息，更接近低波逻辑。
- 绩效：全 A 超额 2.22%、IR 0.32、多空 26.21%、多空夏普 1.71。

### 2.5 振幅因子（海通 55，P0298）
- 股价振幅与未来收益正相关（控制涨跌幅、换手、波动后）。
- 观察期 1-6 个月均有效，但持有期 >3 个月后衰减。
- 振幅因子是对传统价量因子的补充。

### 2.6 跳跃因子（广发 9/46，方正 6）
- 从跳跃-扩散模型出发，用双幂变差（bipower variation）分离跳跃波动。
- 因子：正负向跳跃不对称性 SRJV、正向跳跃波动 RJVP。
- 方正 6：个股股价跳跃及对振幅因子的改进（彩票偏好）。
- 结论：跳跃分量蕴含比已实现波动更多的 alpha。

### 2.7 波动率的波动率（方正 5，P0240）
- 用波动率的波动率刻画模糊性；投资者是模糊性厌恶者。
- 三种度量方式；高模糊性 → 卖出风险资产。

### 2.8 勇攀高峰（方正 3，P0238）
- 用收益波动比衡量"收益率随波动率的变化"。
- 波动率上升 + 收益上升 = 好；波动率上升 + 收益不升 = 风险。

### 2.9 草木皆兵（方正 8，P0243）
- 显著效应：极端高于/低于市场收益的股票吸引过度反应。
- 构造因子捕捉极端收益后的反转。

### 2.10 低 Beta 与低波（财通 9，P0344）
- 简单 Beta 因子走势向下，剔除其他风格暴露的纯 Beta 因子有稳定正收益。
- 高 Beta 股票同时具有高换手、高波动，需正交。

### 2.11 尾部风险理论（外文）
- 重尾分布（Heavy-Tailed Distributions）、跳跃风险、分散化（Risk, jumps, and diversification）。
- 为尾部风险建模提供理论基础。

## 3. 实施流程

```
① 数据：分钟收益、日收益、高频价格
② 波动率估计
   - 已实现波动、已实现偏度/峰度
   - 系统/特质分解（对市场收益回归）
   - 跳跃分离（双幂变差）
   - 上行/下行分解
③ 因子构造
   - 波动率水平、变化、波动率的波动率
   - 收益波动比、振幅、信息分布均匀度
④ 清洗：去极值、标准化、行业/市值中性化、对反转/换手正交
⑤ 测试：IC/RankIC、分层、多空、换手、成本
⑥ 组合：与反转、换手、资金流组合
```

## 4. 关键实证经验

1. **单纯波动率因子选股效果一般**；分解（系统/特质、上行/下行、连续/跳跃）后显著提升。
2. **低波异象在 A 股存在但需正交**：高 Beta 股票的高换手/高波动会干扰。
3. **跳跃因子是增量来源**：已实现波动预测能力有限，跳跃分量更有信息。
4. **振幅因子短期有效、长期衰减**：持有期 >3 个月后多空不显著。
5. **模糊性厌恶**：波动率的波动率是独立风险维度。

## 5. 常见陷阱

| 陷阱 | 说明 | 规避 |
|---|---|---|
| 未复权/未对齐 | 高频价格除权日异常 | 统一复权 |
| 波动率与反转混淆 | 高波动常伴高反转 | 正交后看增量 |
| 未区分系统/特质 | 系统波动是市场 beta | 分解 |
| 跳跃识别错误 | 双幂变差参数/阈值敏感 | 多方法交叉验证 |
| 尾部样本少 | 极端事件统计不稳 | 长样本/极值理论 |
| 交易成本 | 高波因子换手高 | 成本/换手约束 |

## 7. 一页纸总结

- **波动率因子的关键不是"高低"，而是"结构"**：系统/特质、上行/下行、连续/跳跃。
- **最值得先做**：已实现波动分解、特异波动率、跳跃分离、信息分布均匀度。
- **必须做**：对反转/换手/市值正交，否则只是风格代理。
- **别忽略**：尾部风险与模糊性厌恶是独立维度，不能只用方差刻画。
