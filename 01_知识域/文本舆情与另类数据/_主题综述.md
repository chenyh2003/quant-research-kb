# 文本舆情与另类数据 · 主题综述

> 覆盖 11 篇研报｜核心机构：华泰证券（人工智能系列）、中信建投
> 关联知识域：机器学习与AI选股、多因子框架与测试

---

## 1. 这个领域在解决什么问题

文本数据（新闻、研报、业绩预告、公告、社交媒体）包含基本面之外的信息。核心问题：

1. 如何把非结构化文本转成选股因子？
2. 情感分析、事件抽取、主题建模、词频矩阵，哪种方法有效？
3. 文本因子是否有增量？在什么股票池有效？
4. 如何避免文本数据的前视偏差/幸存者偏差？

## 2. 方法谱系

### 2.1 新闻舆情因子（华泰 37，P0083）
- 从 Wind 金融新闻中提取情感正负面标签，构建新闻舆情因子。
- 结论：因子在沪深 300 内表现最好。
- 进一步用 BERT 做文本情感分类。

### 2.2 研报情感因子（华泰 41，P0087）
- 用 BERT 对分析师研报摘要做情感分析。
- 构造 senti / senti_adj 因子；90 个自然日滚动窗口，线性衰减加权。
- 用 LIT 可解释性工具验证模型判断合理性。

### 2.3 文本 PEAD（华泰 51，P0006/P0097）
- 用业绩预告文本（标题 100 词 + 摘要 500 词）构建词频矩阵。
- 标签：业绩预告发布前后 2 个交易日相对中证 500 的超额收益，分上涨/震荡/下跌三类。
- 模型：Logistic / XGBoost；用预测上涨/下跌 log-odds 构造因子。
- 逻辑：文本信息 + PEAD（财报后漂移）。

### 2.4 HAN 新闻舆情（华泰 56，P0102）
- 用层次注意力网络（HAN）处理新闻文本。
- 词级/句级注意力，捕捉关键信息。

### 2.5 文本 FADT（华泰 57/63，P0009/P0103/P0010/P0109）
- FADT（具体定义见原文）文本选股策略。
- 参数敏感性低，多头绝对年化 21%-23%。
- 结论：文本因子较稳健，过拟合风险低。

### 2.6 NLP 综述（华泰 62，P0108）
- 把 NLP 历史分三阶段：统计语言模型 → 神经网络 → 预训练大模型。
- 帮助选择适合量化交易的模型。

### 2.7 新闻共同报道（中信建投，P0066）
- 用新闻共同报道次数刻画股票间关联强度。
- 构建关系型数据增强模型训练（图/关联网络）。
- 与图神经网络、关联因子结合。

### 2.8 ChatGPT 与股价预测（外文，P0073）
- 研究 LLM 对新闻标题的情感判断是否能预测股价。
- 结论：LLM 有一定预测能力，但需注意样本期/市场有效性。

## 3. 实施流程

```
① 数据采集
   - 新闻、研报、业绩预告、公告、社交媒体
   - 记录发布时间（point-in-time）
② 文本预处理
   - 分词、去停用词、词性过滤
   - 去重、去广告、去免责声明
③ 文本表示
   - 词频矩阵/TF-IDF
   - 词向量/预训练模型（BERT）
   - 主题模型/事件抽取
④ 情感/事件建模
   - 有监督情感分类（标注数据）
   - 无监督情感词典
   - LLM 零样本/少样本
⑤ 因子构造
   - 情感均值/变化/离散度
   - 事件强度/方向
   - 共同报道关联度
⑥ 测试
   - IC/RankIC、分层、多空
   - 不同股票池（全 A/沪深 300/中证 500）
   - 与量价/基本面因子相关性
⑦ 组合
   - 与多因子模型结合；控制换手/成本
```

---

## 4. 关键实证经验

1. **舆情因子在沪深 300 内表现最好**（华泰 37）：大市值股票新闻覆盖更充分。
2. **研报情感因子有增量**（华泰 41）：senti/senti_adj 可作为另类因子。
3. **文本 PEAD 有效**（华泰 51）：业绩预告文本 + 事件窗口超额收益。
4. **文本 FADT 参数不敏感、多头年化 21%-23%**（华泰 57）：稳健性较好。
5. **新闻共同报道可构建关联网络**（中信建投）：关系型数据增强。
6. **LLM 情感分析有预测能力但有限**（外文）：不能高估。

## 5. 常见陷阱

| 陷阱 | 说明 | 规避 |
|---|---|---|
| 前视偏差 | 用了发布后修改的文本/标签 | 记录发布时间，point-in-time |
| 文本去重 | 同一新闻多源转载 | 去重/聚类 |
| 情感标注偏差 | 人工标注主观 | 多人标注/一致性检验 |
| 覆盖率偏差 | 小市值股票新闻少 | 分股票池测试 |
| 过拟合 | 词典/模型在样本内调优 | 时序CV/样本外 |
| 计算成本 | BERT/LLM 推理贵 | 批处理/蒸馏/缓存 |
| 数据版权 | 新闻/研报版权 | 合规使用 |

## 7. 一页纸总结

- **文本因子的核心**：情感（正/负）、事件（业绩/新闻）、关系（共同报道）。
- **最稳的方向**：研报情感、文本 PEAD、FADT；新闻舆情在大市值更有效。
- **必须做**：point-in-time、去重、覆盖率检验、时序CV。
- **别高估**：LLM 情感预测能力有限，不能替代严谨回测。
