# 统计方法与过拟合 · 主题综述

> 覆盖 1 篇主研报 + 多篇交叉研报｜核心机构：华泰证券、财通证券
> 关联知识域：机器学习与AI选股、多因子框架与测试

---

## 1. 这个领域在解决什么问题

量化研究最大的敌人不是"没有因子"，而是"把噪声当成信号"。核心问题：

1. 如何检验一个回测结果是否过拟合？
2. 时序数据为什么不能用传统交叉验证？
3. Bootstrap 重采样如何构造"平行世界"？
4. 回测过拟合概率（PBO）怎么算？
5. 随机种子、参数敏感性如何影响结论？
6. 时序自相关/异方差下如何做显著性检验？

## 2. 方法谱系

### 2.1 时序交叉验证（华泰 14/16，P0115/P0117）
- 传统 K 折 CV 会泄漏未来信息。
- 时序 CV：训练集在前、验证集在后，滚动切分。
- 改进：基线模型设置 + 训练/验证精确切分。
- 结论：时序 CV 训练集表现较差，但测试集更好；传统 CV 过拟合明显。

### 2.2 Bootstrap 重采样（华泰 19，P0120）
- 有放回抽样，构造"平行世界"。
- 对样本内、样本外、回测时间分别重采样。
- 若结论在平行世界复现，过拟合概率低。

### 2.3 回测过拟合概率 PBO（华泰 22，P0124）
- 基于 CSCV（组合对称交叉验证）。
- 把样本切成多个子区间，组合成训练/测试集，计算"最优策略在样本外排名"的分布。
- PBO 越低越好；多因子选股 15%-50%，择时模型较高。

### 2.4 随机种子（华泰 20，P0122）
- 逻辑回归不敏感；全连接网络敏感；XGBoost/随机森林居中。
- 结论需报告多种子分布，而非单次最优。

### 2.5 参数敏感性（华泰 57，P0009）
- 参数平原优于参数尖峰。
- 文本 FADT 参数不敏感 → 过拟合概率低。

### 2.6 Newey-West 调整（财通 17，P0335）
- 处理异方差与自相关。
- 自相关系数 > 0 时 NW 标准误 > OLS；反之亦然。
- 用于因子收益 t 值的稳健推断。

### 2.7 显著性检验（财通 13/2，P0349/P0338）
- 多因子模型 t 值计算：注意截距/行业收益包含市场收益会导致高估。
- R² 在不加截距回归中可能为负；总 R² 与相对 R² 含义不同。

### 2.8 多重检验（通用）
- 测试大量因子/参数时，假阳性增加。
- 方法：Bonferroni、FDR、White's Reality Check、Deflated Sharpe Ratio。
- 本库研报未系统展开，但 PBO/重采样是相关实践。

## 3. 实施流程（研究验收清单）

```
① 数据：point-in-time、无幸存者偏差
② 切分：训练/验证/测试按时间切分
③ 预处理：只在训练集拟合（标准化/去极值/缺失值）
④ 模型：时序 CV 选超参
⑤ 回测：扣除成本、换手约束
⑥ 稳健性：
   - 多种子
   - 参数敏感性
   - 分年度/分股票池
   - Bootstrap/重采样
   - PBO
⑦ 显著性：Newey-West t 值
⑧ 样本外：留出最近 1-3 年
```

---

## 4. 关键经验

1. **时序 CV 是底线**：不做时序 CV 的机器学习回测基本不可信。
2. **PBO 是"最优模型"的照妖镜**：PBO 高说明"最佳"只是噪声。
3. **随机种子必须报告**：尤其神经网络。
4. **参数平原 > 参数尖峰**：稳健性比最优点重要。
5. **Newey-West 是因子显著性的标配**：忽略自相关会高估 t 值。

---

## 5. 常见陷阱

| 陷阱 | 说明 | 规避 |
|---|---|---|
| 用未来数据做预处理 | 全样本标准化/去极值 | 训练集内拟合 |
| 传统 K 折 CV | 时序泄漏 | 时序 CV |
| 只报最优种子 | 不可复现 | 多种子分布 |
| 只报最优参数 | 过拟合 | 参数敏感性/平原 |
| 忽略多重检验 | 假阳性 | FDR/Deflated Sharpe |
| 忽略自相关 | t 值高估 | Newey-West |
| 样本外反复使用 | 样本外变样本内 | 留最终测试集 |

## 7. 一页纸总结

- **防过拟合三件套**：时序 CV + 重采样/PBO + 随机种子分布。
- **显著性标配**：Newey-West t 值。
- **最容易被忽略**：预处理泄漏、样本外反复使用、多重检验。
- **一句话**：如果结论只在一次回测中成立，它大概率不成立。
