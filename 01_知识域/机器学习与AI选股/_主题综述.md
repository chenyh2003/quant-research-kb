# 机器学习与AI选股 · 主题综述

> 覆盖 76 篇研报｜核心机构：华泰证券（人工智能系列 1-68）、海通证券、中信建投、东方证券、开源证券
> 关联知识域：高频量价因子、文本舆情与另类数据、统计方法与过拟合

---

## 1. 这个领域在解决什么问题

把选股从"人工构造因子 + 线性加权"扩展到"数据驱动 + 非线性模型"。核心问题：

1. **模型选择**：线性、树模型、神经网络、图网络、强化学习，各自适合什么场景？
2. **标签设计**：用收益率、分类标签、IR/Calmar、有序回归，还是另类标签？
3. **特征工程**：量价、基本面、高频、文本、图关系，如何构建/筛选/融合？
4. **过拟合治理**：时序交叉验证、重采样、PBO、随机种子、样本外。
5. **工程落地**：调仓频率、组合优化、换手控制、可解释性。

## 2. 问题框架（先想清楚再选模型）

| 问题类型 | 标签 | 常用模型 | 评价 |
|---|---|---|---|
| 回归 | 未来 N 日收益率 | 线性回归、XGBoost、神经网络 | IC、MSE、分层 |
| 二分类 | 涨/跌、跑赢/跑输 | 逻辑回归、SVM、树模型、NN | AUC、准确率、多空 |
| 多分类 | 涨/震荡/跌 | 逻辑回归、XGBoost、NN | 混淆矩阵、多空 |
| 排序 | 横截面收益排序 | LambdaMART、有序回归 | RankIC、NDCG |
| 组合 | 直接输出权重 | 强化学习、神经网络组合优化 | 夏普、回撤、换手 |

> 华泰 60：有序回归（ordinal regression）适合"模糊的正确"，比硬分类更贴合选股排序需求。

## 3. 模型谱系（按复杂度）

### 3.1 线性与广义线性（华泰 1/2）
- 线性回归、岭回归、Lasso、弹性网、逻辑回归
- 优点：可解释、稳定、不易过拟合；缺点：无法捕捉非线性/交互
- 用途：基准模型、因子合成、可解释性对照

### 3.2 核方法与概率模型（华泰 3/4）
- SVM（线性核/多项式核/高斯核/Sigmoid 核）、SVR
- 朴素贝叶斯、LDA、QDA（生成模型）
- 适合中小样本、非线性边界；对特征缩放敏感

### 3.3 树模型与集成（华泰 5/6/11）
- 随机森林（Bagging）
- AdaBoost、GBDT、XGBoost（Boosting）
- Stacking（多层集成）
- 优点：非线性、特征交互、对异常值稳健；缺点：过拟合、调参多
- 华泰 11：改进 Stacking 适合金融数据；第一层模型需差异化

### 3.4 神经网络（华泰 8/9/15）
- 全连接网络（FC）
- 循环网络：RNN、LSTM、GRU（时序）
- 卷积网络：CNN、TCN（局部模式/长序列）
- 优点：非线性、端到端；缺点：黑箱、随机种子敏感、易过拟合

### 3.5 图神经网络（华泰 42/55/58/61）
- GCN/GAT，利用股票间关联（行业、共同覆盖、新闻共同报道、供应链）
- 适合捕捉横截面关联与溢出效应
- 难点：图构建、边权重、动态图

### 3.6 生成模型（华泰 31/35/36/38/44/45/47/48/49/50）
- GAN、WGAN、RGAN、cGAN、SinGAN
- 用途：金融时间序列生成、数据增强、宏观指标模拟、策略调参、资产配置
- 注意：生成数据不能直接替代真实数据做回测结论

### 3.7 遗传规划与 AutoML（华泰 21/23/54；中信建投 12/13/15；东方 90/95）
- 遗传规划：公式演化，自动挖掘因子；适合量价/基本面/一致预期
- AutoML-Zero、openFE：自动化特征工程/因子挖掘
- 风险：过拟合、可解释性、计算成本

### 3.8 强化学习（华泰 59；东方 95）
- DQN、策略梯度、REINFORCE，用于择时/订单执行/组合
- 难点：奖励设计、样本效率、非平稳、回测偏差

## 4. 标签设计（被低估的关键）

| 标签 | 代表 | 特点 |
|---|---|---|
| 未来收益率 | 华泰 1-10 | 最常用；只利用区间两端价格 |
| 涨/跌分类 | 华泰 1-10 | 稳定；丢失幅度信息 |
| 夏普/信息比率/Calmar | 华泰 17/29 | 另类标签，包含区间波动/回撤信息 |
| 有序回归 | 华泰 60 | 保留排序信息，适合"模糊的正确" |
| 多任务 | 华泰 67 | 同时预测收益/风险/风格 |
| 文本 PEAD 标签 | 华泰 51 | 业绩预告后涨/震荡/跌 |

> 华泰 29：另类标签（IR/Calmar）在全 A 股显著提升超额收益和信息比率；在指数成分股内优势较小；另类标签模型回撤更大，需谨慎。

## 5. 特征工程

### 5.1 特征来源
- 日频量价：动量、反转、波动、换手、流动性、市值、估值
- 高频量价：分钟/快照/逐笔因子（见高频域）
- 基本面：盈利、成长、质量、杠杆、分析师预期
- 文本：新闻舆情、研报情感、业绩预告、FADT
- 图关系：行业、共同覆盖、新闻共同报道、供应链
- 宏观/周期：周期三因子、PMI、利率

### 5.2 特征处理
- 缺失值、去极值、标准化、中性化（见多因子域）
- 特征选择：过滤法、包裹法、嵌入法；华泰 12 发现对逻辑回归/XGBoost 有提升
- 特征归因：特征重要性、SHAP、LIME、ICE、PDP、SDT（华泰 27）
- 多颗粒度：同一特征在多个频率计算，可能互有增益（海通 88）

### 5.3 高频深度学习特征工程（海通 76/79/86/87/88/93/97）
- 输入：分钟/逐笔指标序列
- 模型：RNN+NN、GRU/LSTM、注意力、TCN、BiAGRU、BiATCN
- 改进：注意力解决长序列遗忘；多颗粒度融合；混频（日频+60 分钟）；GNN 融合基本面
- 经验：周度选股能力显著；模型集成（模型动物园）可提升稳定性

## 6. 过拟合治理（必读）

### 6.1 时序交叉验证（华泰 14/16）
- 传统 K 折 CV 对时序数据会泄漏未来信息
- 时序 CV：训练集在前、验证集在后，滚动切分
- 华泰 16：改进基线模型设置与样本精确切分，进一步降低过拟合

### 6.2 重采样检验（华泰 19）
- Bootstrap 有放回重采样，构造"平行世界"
- 若结论在平行世界复现，过拟合概率低

### 6.3 回测过拟合概率 PBO（华泰 22）
- 基于 CSCV（组合对称交叉验证）计算 PBO
- 案例：多因子选股 PBO 15%-50%；择时模型 PBO 较高
- 用途：评估"最优模型"是否只是回测噪声

### 6.4 随机种子（华泰 20）
- 逻辑回归对随机种子不敏感；全连接网络敏感；XGBoost/随机森林居中
- 结论需在多种子下测试，报告分布而非单次结果

### 6.5 参数敏感性
- 华泰 57（文本 FADT）：参数不敏感 → 过拟合概率低
- 参数平原优于参数尖峰

## 7. 工程落地

### 7.1 调仓频率（华泰 18）
- 月频机器学习模型 2017 年后超额下滑
- 周频 XGBoost 表现最好；需组合优化控制换手

### 7.2 组合优化（华泰 39/52）
- 风险模型：行业、市值、风格
- 约束：个股权重、行业偏离、换手、跟踪误差
- 神经网络组合优化（华泰 52）可端到端学习权重

### 7.3 可解释性（华泰 27/30）
- 特征重要性、SHAP、LIME、ICE、PDP、SDT
- 因果推断（华泰 30）：倾向性评分法，区分因果与虚假关联
- 资管伦理要求白箱/可解释，黑箱模型需额外解释层

### 7.4 平台与工具
- Qlib（华泰 40/42/53）：微软 AI 量化平台，覆盖数据/模型/回测/组合
- Python 生态：NumPy、pandas、scikit-learn、XGBoost、PyTorch/TensorFlow
- 工程化：Memory Map 加速因子生产（国盛 9）

## 8. 关键实证经验

1. **没有"最好模型"，只有"适合数据/标签/频率的模型"**。华泰系列测试了几十种模型，差异主要来自数据/标签/工程，而非模型本身。
2. **另类标签 + 集成学习是稳定提升方向**（华泰 29）。
3. **周频优于月频**（华泰 18），但换手/成本更高，需组合优化。
4. **时序 CV 是防过拟合的最低要求**（华泰 14/16）。
5. **随机种子必须报告**（华泰 20），否则结论不可复现。
6. **高频深度学习因子的关键是特征工程与序列建模**（海通 86/88），不是堆模型。
7. **遗传规划能挖出增量因子，但可解释性和过拟合是主要风险**（华泰 21/23）。
8. **文本因子参数不敏感、多头年化 21%-23%**（华泰 57），是另类数据中较稳的方向。

## 9. 常见陷阱

| 陷阱 | 表现 | 规避 |
|---|---|---|
| 数据泄漏 | 用了未来数据/全样本标准化 | 严格时序切分，训练集内拟合预处理 |
| 过拟合 | 回测极好、实盘失效 | 时序 CV、PBO、重采样、样本外 |
| 随机种子挑选 | 只报最好种子 | 多种子分布、均值/方差 |
| 标签泄漏 | 标签计算用了未来信息 | 标签与特征时间对齐 |
| 样本不平衡 | 涨跌样本失衡 | 重采样、类别权重、有序回归 |
| 交易成本低估 | 高换手模型收益虚高 | 成本模型、换手约束 |
| 黑箱不可解释 | 无法归因/风控 | SHAP/LIME/因果推断 |
| 生成数据滥用 | 用 GAN 数据得出回测结论 | 生成数据只用于增强/压力测试 |
| 因子拥挤 | 机器学习因子同质化 | 多数据源、多频率、多模型 |

## 11. 一页纸总结

- **先数据/标签，后模型**：模型差异往往小于标签/特征/时序处理的差异。
- **防过拟合三件套**：时序 CV + 重采样/PBO + 随机种子分布。
- **稳定提升组合**：另类标签 + 集成学习 + 周频 + 组合优化。
- **高频深度学习**：特征工程 > 模型复杂度；注意力/多颗粒度/混频是有效方向。
- **最值得警惕**：数据泄漏、随机种子挑选、生成数据滥用、黑箱不可解释。
