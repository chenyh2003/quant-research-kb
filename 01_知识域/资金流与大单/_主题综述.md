# 资金流与大单 · 主题综述

> 覆盖 21 篇研报｜核心机构：海通证券、开源证券、东方证券、长江证券、国信证券、招商证券、华安证券
> 关联知识域：高频量价因子、订单簿与订单流、市场微观结构理论

---

## 1. 这个领域在解决什么问题

资金流因子试图回答"谁在买、谁在卖、买了多少"。核心问题：

1. 如何从逐笔成交/委托中划分大单、中单、小单？
2. 大单/小单资金流是否有 alpha？方向如何？
3. 主买/主卖、主动成交度如何刻画？
4. 如何识别知情交易、聪明钱、羊群效应？
5. 资金流因子为什么会失效？如何改进？

---

## 2. 数据与划分

| 数据 | 字段 | 用途 |
|---|---|---|
| 逐笔成交 | 成交价、量、BS 标志、叫买/叫卖序号 | 主买主卖、大单、成交笔数 |
| 逐笔委托 | 委托价、量、方向、撤单 | 订单流、委托规模 |
| 快照 | 十档买卖价量 | 盘口资金流近似 |

**大单划分方法**：
1. 固定金额阈值（如 >100 万/500 万）
2. 分位数阈值（如当日订单金额前 5%/10%）
3. 基于股票自身成交额分布（海通 72：更有逻辑的阈值）
4. 基于逐笔委托单号合成订单金额（东方 79：解决深交所覆盖问题）

> 关键：不同股票、不同时期的成交额分布差异大，固定阈值会失真；分位数/自适应阈值更稳健。

## 3. 方法谱系

### 3.1 Level2 因子初探（海通 11，P0251）
- 早期探索 Level2 数据的选股因子，包括盘口、委托、成交。
- 结论：Level2 类因子有进一步挖掘空间。

### 3.2 大单成交金额占比与集中度（海通 52，P0261）
- 基于逐笔成交的叫买/叫卖序号合成买卖单数据。
- 因子：大买成交金额占比、大买大卖成交金额占比差值、买单集中度、卖单集中度。
- 结论：正交后大买占比、大买大卖差值显著正向；集中度因子正交前后均显著，主要在中小学市值。

### 3.3 主买占比与主买强度（海通 57，P0263）
- 用逐笔成交的 BS 标志，降频合成分钟级主买/主卖金额。
- 因子：主买占比、主买强度。
- 结论：正交后仍有月度选股能力；沪深 300 内多头效应更强。

### 3.4 知情交易与主买主卖（海通 58，P0264）
- 用知情交易概率模型（PIN/VPIN 类）过滤主买/主卖。
- 因子：知情主买、知情主卖。
- 逻辑：区分知情交易与流动性交易，提升信号纯度。

### 3.5 大单精细化与大单因子重构（海通 72，P0272）
- 改进大单阈值：用更有逻辑的筛选阈值（而非固定金额）。
- 结论：重构后大单因子选股能力提升。

### 3.6 买卖单主动成交中的隐藏信息（海通 85，P0277）
- 买单/卖单并非完全由主动买入/卖出构成。
- 计算大单/中单/小单的主动成交度，构造因子。
- 结论：小单主动成交度等信息有增量。

### 3.7 超大单冲击（东方 82，P0044）
- 基于 L2 高频数据构建大单买入占比、大单涨跌幅因子。
- 研究超大单冲击对大单因子的影响，提出改进。
- 逻辑：超大单可能是机构建仓/出货，也可能是对倒，需要区分。

### 3.8 大小单资金流（开源 12/16/18/26）
- 开源 12：大单与小单资金流的 alpha 能力。
- 开源 16：大小单重定标与资金流因子改进（解决量纲/分布问题）。
- 开源 18：大小单资金流 alpha 2.0，变量精筛与高频测算。
- 开源 26：资金流与交易行为，因子失效的原因与讨论。
- 核心：大单/小单资金流都有 alpha，但方向/稳定性不同；需重定标、精筛、理解失效机制。

### 3.9 分钟单笔金额序列中的主力行为（开源 15，P0206）
- 用分钟单笔金额序列刻画主力行为。
- 因子：单笔金额的分布、集中度、时序特征。

### 3.10 聪明钱因子 2.0（开源 3，P0224）
- 用交易行为识别"聪明钱"（机构/知情交易者）。
- 2.0 版本改进因子构造。

### 3.11 羊群效应（开源 14、广发 3、国盛 7/14）
- 识别趋势资金/主力之后的跟随者行为。
- 因子：羊群效应强度、跟随者交易占比、逐笔羊群因子。
- 逻辑：羊群效应过强 → 过度反应 → 未来反转。

### 3.12 资金流动力学（开源 14，P0205）
- 不只静态资金流，还看资金流的动态变化（加速度、持续性、切换）。
- 结合散户羊群效应。

### 3.13 小单流入额（长江 5，P0360）
- 小单流入额因子 IC -9.90%，分组单调。
- 但本质是量价类指标，与成交额、市值高度相关；剔除流动性属性后 IC -3.62%，仍有价值。
- 启示：资金流因子必须正交化，区分"真增量"与"流动性代理"。

## 4. 实施流程

```
① 数据准备
   - 逐笔成交/委托，BS 标志、叫买叫卖序号
   - 合成买卖单、订单金额
② 大小单划分
   - 固定阈值/分位数/自适应阈值
   - 分股票、分时期校准
③ 因子构造
   - 占比类：大买占比、主买占比、小单流入占比
   - 差值类：大买-大卖、主买-主卖
   - 集中度类：买单/卖单集中度
   - 主动成交度、知情交易过滤
   - 动态类：资金流加速度、持续性
④ 清洗
   - 去极值、标准化、行业/市值中性化、对成交额/换手正交
⑤ 测试
   - IC/RankIC、分层、多空、换手、成本
   - 与量价/流动性因子相关性
⑥ 组合
   - 与反转、换手、波动、订单流因子组合
```

## 5. 关键实证经验

1. **大单因子有 alpha，但必须正交**：小单流入额 IC -9.9% → 正交后 -3.62%（长江 5）。
2. **大买占比、主买占比在正交后仍显著**（海通 52/57）。
3. **集中度因子在中小学市值更有效**（海通 52）。
4. **超大单需要单独处理**：可能是机构也可能是对倒（东方 82）。
5. **资金流因子会失效**：开源 26 专门讨论失效原因（拥挤、结构变化、交易行为变化）。
6. **羊群效应是双刃剑**：适度跟随有信息，过度跟随反转（开源 14、国盛 7）。

## 6. 常见陷阱

| 陷阱 | 说明 | 规避 |
|---|---|---|
| 固定大单阈值 | 不同股票/时期失真 | 分位数/自适应阈值 |
| 资金流=流动性代理 | 与成交额/换手高度相关 | 正交化后看增量 |
| 大单=机构 | 大单可能是对倒/游资 | 结合主动成交度/知情交易 |
| 忽略方向 | 只看流入不看主动买卖 | 区分主买/主卖 |
| 忽略失效 | 因子拥挤/结构变化 | 监控 IC 衰减、拥挤度 |
| 高频→低频逻辑反转 | 资金流高频/低频方向不同 | 分频率测试 |
| 交易成本 | 高换手 | 成本/换手约束 |

## 8. 一页纸总结

- **资金流因子的核心**：谁在买（大单/小单）、怎么买（主买/主动成交）、买了多少（占比/集中度）、是否知情（PIN/羊群）。
- **最稳的因子**：大买占比、主买占比、大买-大卖差值（正交后仍显著）。
- **必须做**：自适应大单阈值、正交化、方向检验、失效监控。
- **最大误区**：把资金流当独立 alpha，忽略它本质是流动性/量价的代理。
