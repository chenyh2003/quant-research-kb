# 多因子框架与测试 · 主题综述

> 覆盖 52 篇研报｜核心机构：光大证券、财通证券、国盛证券、海通证券、银河证券、东北证券、东方证券
> 关联知识域：统计方法与过拟合、机器学习与AI选股、行业轮动与组合配置

---

## 1. 这个领域在解决什么问题

多因子模型是把"预测股票收益"拆成"预测因子收益"+"控制风险暴露"的工程体系。它要回答：

1. 如何管理数据、构建因子库？
2. 如何清洗因子（去极值、标准化、缺失值、中性化、正交化）？
3. 如何检验单因子有效（IC、分层、回归、纯因子）？
4. 如何筛选、合成、赋权因子？
5. 如何构建风险模型、做组合优化？
6. 如何避免前视、幸存者、过拟合等回测陷阱？

---

## 2. 全流程框架

```
数据管理
  → 数据预处理（异常值、标准化、缺失值、正交化）
  → 单因子研究（逻辑解释、多空组合、IC）
  → 因子筛选（增量信息、显著性、相关性）
  → 因子赋权/合成（等权、IC/ICIR、最大化 IR、Lasso、ML）
  → 风险模型（行业、市值、风格）
  → 组合优化（收益预测、风险约束、换手约束）
  → 回测与归因
```

**权威底稿**：东方证券《多因子量化投资体系手册》（P0186）把体系拆成数据管理、数据预处理、单因子研究、线性多因子 Alpha 模型、风险模型、投资组合管理六大模块，并附兴业因子库定义与表现。

## 3. 数据预处理

### 3.1 异常值处理（财通拾穗第 5 期，P0341）
常用方法：
1. 均值标准差修正法（3σ）
2. 固定比率修正法
3. 中位数去极值法（MAD）
4. Beat G. Briner 方法
5. 因子排序值标准化法
6. 箱形图法
7. 无量纲处理方法

经验：财务数据（尤其增长率类）异常值多于价量数据；不同方法差异不大，但必须处理。

### 3.2 标准化
- Z-score：`(x - mean) / std`
- Rank 标准化：排序后映射到正态/均匀分布，对异常值更稳健
- 注意：市值等右偏分布先取对数

### 3.3 缺失值处理（财通拾穗第 6 期，P0342）
方法：
1. 市场均值填充
2. 行业均值填充
3. 市值分组均值填充
4. 前向填充
5. 结构化填充（推荐）：利用其他因子/行业/市值信息建模填充

经验：价量因子覆盖率优于财务因子；结构化填充效果最优。

### 3.4 中性化与正交化
- **行业中性**：对行业哑变量回归取残差，或行业内排序
- **市值中性**：对市值（对数）回归取残差
- **因子正交**：剔除其他因子的线性影响（回归法）或分组法
- 财通拾穗第 18 期（P0345）：回归法简单但只剔除线性；分组法中性化更好但只能单因子、难与组合优化衔接
- 海通《选股因子的正交》（P0287）：系统讨论正交的样本选择、顺序、效果
- 财通拾穗第 7 期（P0343）：从纯因子组合角度理解多重共线性；VIF < 3 较安全

### 3.5 财务数据时点对齐（财通拾穗第 16 期，P0347）
- 两大难题：发布滞后、数据修正
- 影响：同比增速、单季度、TTM
- 不修正 → 前向偏差，回测虚高；按公告截止日调整 → 仍滞后；直接用第三方修正后数据 → 可能间接使用未来数据
- 正确做法：用"当时可见"的原始公告数据 + 发布日期对齐，构建 point-in-time 数据集

## 4. 单因子测试

### 4.1 四种主流方法（财通拾穗第 7 期，P0343）
1. **分组法**：按因子值分 N 组，看各组收益单调性/多空
2. **Fama-MacBeth**：逐期横截面回归，因子收益序列
3. **简单因子组合法**：组合每增加一单位因子暴露的收益影响
4. **纯因子组合法**：剔除其他因子影响后，目标因子的风险溢价

### 4.2 光大因子测试框架（P0060/P0062）
- 分期截面 RLM 稳健回归（代替 OLS，抗异常值）
- 因子收益 t 值、累计收益率、IC、IR、多空收益、最大回撤、换手率
- 分层回测检验单调性
- 结论：行情类因子（流动性、波动、动量）整体优于财务类；分析师预期因子值得关注

### 4.3 关键指标
| 指标 | 含义 | 经验阈值 |
|---|---|---|
| IC 均值 | 因子值与下期收益的截面相关 | |IC| > 0.03 有意义，> 0.05 较好 |
| RankIC | 排序相关，抗异常值 | 同上 |
| ICIR | IC 均值/IC 标准差 | > 0.5 较好，> 1 优秀 |
| 多空年化 | 多空组合收益 | 视市场/成本 |
| 信息比 | 多空年化/多空波动 | > 1 较好 |
| 月胜率 | 多空月度正收益比例 | > 60% 较好 |
| 最大回撤 | 多空净值最大回撤 | 越小越好 |
| 换手率 | 组合换手 | 与成本匹配 |
| t 值 | 因子收益显著性 | > 2 显著 |

### 4.4 显著性推断
- 财通拾穗第 13 期（P0349）：多因子模型中 t 值的计算，注意截距/行业收益包含市场收益会导致 t 值高估
- 财通拾穗第 17 期（P0335）：Newey-West 调整处理异方差与自相关；自相关系数 > 0 时 NW 标准误大于 OLS（反之亦然）
- 财通拾穗第 2 期（P0338）：R² 在不加截距回归中可能为负；总 R² 与相对 R² 含义不同

## 5. 因子筛选与合成

### 5.1 筛选
- 东北多因子系列（P0016/P0017）：通过比较加入新因子后基准模型截距项变化，判断是否提供增量信息
- 财通拾穗第 1 期（P0348）：带约束的加权最小二乘，解析解法（排他/等式/一般线性约束）
- 银河《因子组合的确定》（P0355）：因子暴露度、相关强度、选股能力三标准
- 国盛多因子系列（P0167）：因子配置、因子改进、尾部风险

### 5.2 合成/赋权
1. 等权
2. IC 加权
3. ICIR 加权
4. 最大化 IR（Edward Qian；光大动态最优化 IR，P0061）
5. Lasso/正则化（国盛多因子 2，P0171）
6. 机器学习（树模型/神经网络）
7. 分层/分域合成（行业、信息透明度、久期）

> 光大 P0061：滚动 36 个月、持仓 150 只的等权组合最优，信息比 3.67、年化 31%；动态 IR 显著高于静态赋权。

## 6. 风险模型与组合优化

- **风险模型**：行业 + 市值 + 风格（Barra 类）；东方手册第 6 章有基本面风险模型详解
- **组合优化**：最大化预期收益 - 风险惩罚，约束行业/市值/个股/换手
- **指数增强**：
  - 东北《指数增强视角下的因子检验、合成与组合优化》（P0015）
  - 华泰《周频量价选股模型的组合优化实证》（P0085）
  - 国盛《结合行业轮动的沪深 300 指数增强》（P0229）
  - 海通《剔除高频因子空头组合后的中证 500 指数增强》（P0306）
- **回撤控制**：申万宏源《如何在组合中合理加入回撤控制机制？》（P0327）
- **换手控制**：周频模型必须用组合优化控制换手（华泰 18，P0119）

## 8. 常见陷阱（重点）

| 陷阱 | 说明 | 规避 |
|---|---|---|
| 前视偏差 | 财务数据用了发布后修正的数据 | Point-in-time 数据；按公告日对齐 |
| 幸存者偏差 | 只保留当前上市股票 | 保留退市/暂停上市样本 |
| 行业分类变更 | 借壳/并购导致行业变化 | 用历史行业分类，按事件日切换 |
| 市值口径混淆 | 总市值/流通市值/自由流通市值 | 明确口径，通常用自由流通市值 |
| 多重共线性 | 因子高度相关，回归系数不稳 | VIF 检查、正交化、纯因子组合 |
| 显著性高估 | 时序自相关/异方差 | Newey-West 调整 |
| 样本内调参 | 参数在全样本寻优 | 时序交叉验证、样本外、参数敏感性 |
| 忽略交易成本 | 高换手因子收益被成本吞噬 | 双边成本+冲击成本+换手约束 |
| 因子拥挤 | 同类因子失效 | 监控相关性/拥挤度；多逻辑分散 |
| 数据供应商错误 | 第三方衍生数据口径不一致 | 交叉校验，回到原始数据 |

## 10. 一页纸总结

- **多因子不是"找因子"，而是"数据→测试→合成→风险→组合"的工程**。
- **最容易被忽视的三件事**：Point-in-time 数据、Newey-West 显著性、交易成本。
- **最稳的测试组合**：分层 + IC/RankIC + 纯因子回归 + 正交后增量。
- **因子合成的优先级**：先等权/ICIR，再考虑 Lasso/ML；不要用复杂模型掩盖数据问题。
- **下一步**：进入 `03_问题解决方案库` 的"因子测试/正交化/过拟合"问题卡。
