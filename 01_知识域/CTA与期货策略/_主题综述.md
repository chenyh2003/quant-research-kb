# CTA与期货策略 · 主题综述

> 覆盖 3 篇研报｜核心机构：华泰证券、华创证券
> 关联知识域：高频量价因子、机器学习与AI选股、市场微观结构理论

> 注：本库 CTA 内容较少；用户自己的沪铜 CTA 策略包（v2.2-v3.5）不在本知识库范围内，可作为实践补充。

---

## 1. 这个领域在解决什么问题

CTA（Commodity Trading Advisor）策略在期货市场做趋势/反转/套利。核心问题：

1. 如何从量价数据中挖掘 CTA 信号？
2. 遗传规划如何用于 CTA 信号挖掘？
3. 龙虎榜/成交量等特征如何用于择时？
4. 期货与股票的高频因子表现有何差异？

---

## 2. 方法谱系

### 2.1 遗传规划 CTA 信号挖掘（华泰 26，P0128）
- 用 gplearn 定制遗传规划，在多个商品期货品种上挖掘信号。
- 优势：大规模启发式搜索，突破人工思维局限。
- 输出：回测效果较好且意义明确的 CTA 信号。
- 风险：过拟合、可解释性、计算成本。

### 2.2 龙虎榜机构模型（华创 1，P0386）
- 用龙虎榜机构席位信息构建择时模型。
- 行为金融有限注意力理论：机构席位上榜 → 关注度 → 后续收益。
- 用于特征分布建模择时。

### 2.3 特征成交量做空模型（华创 2，P0387）
- 成交量放量上涨/缩量下跌规律。
- 构建成交量特征分布择时模型，包括做空模型。
- 结论：成交量特征可补充传统择时。

### 2.4 股票与期货高频因子对比（海通 0，P0282）
- 高频因子在股票与期货中的表现对比。
- 结论：部分因子在期货中更有效/更弱，需分市场测试。

## 3. 实施流程

```
① 品种选择：商品/股指/国债；主力连续合约
② 数据：日线/分钟/高频；持仓量、成交量
③ 信号挖掘
   - 人工逻辑：趋势、反转、突破、波动率
   - 遗传规划：公式演化
   - 机器学习：树模型/神经网络
④ 回测
   - 合约乘数、保证金、手续费、滑点
   - 主力换月、涨跌停、夜盘
⑤ 组合
   - 多品种分散、风险预算、波动率目标
⑥ 实盘
   - 信号次日执行、整数手、风控
```

---

## 4. 关键经验

1. **遗传规划能挖出增量 CTA 信号，但必须控制过拟合**（华泰 26）。
2. **期货高频因子与股票不同**：需分市场测试（海通 0）。
3. **龙虎榜/成交量特征可做择时补充**（华创 1/2）。
4. **CTA 的核心是风险管理**：仓位、止损、多品种分散比信号更重要。

---

## 5. 常见陷阱

| 陷阱 | 说明 | 规避 |
|---|---|---|
| 主力换月 | 价差/跳空 | 检测切换，平旧开新 |
| 涨跌停 | 无法成交 | 禁开/平仓，止损顺延 |
| 保证金/杠杆 | 爆仓风险 | 风险预算 |
| 过拟合 | 遗传规划/参数寻优 | 样本外/时序CV |
| 成本 | 高频/换手 | 手续费+滑点 |
| 夜盘 | 交易时段不同 | 分时段处理 |

## 7. 一页纸总结

- **CTA 信号挖掘**：人工逻辑 + 遗传规划 + 机器学习，三者互补。
- **最值得先读**：华泰 26（遗传规划 CTA）、海通 0（股期高频因子对比）。
- **必须做**：主力换月、涨跌停、保证金、成本、样本外。
- **别忽略**：CTA 的胜负在风险管理，不在信号复杂度。
