# 订单簿与订单流 · 主题综述

> 覆盖 13 篇研报 + 1 本专著｜核心机构：中信建投、海通证券、东吴证券、开源证券、东方证券、国金证券
> 关联知识域：高频量价因子、资金流与大单、市场微观结构理论

---

## 1. 这个领域在解决什么问题

订单簿是市场供需的实时记录。价格不是外生给定的，而是由逐笔委托、撤单、成交自下而上"撮合"出来的。订单簿与订单流研究要回答：

1. 如何从 Level2 快照/逐笔数据中还原订单簿？
2. 哪些盘口特征（失衡、斜率、价差、深度、撤单）能预测短期收益？
3. 如何把毫秒/秒级信号降为日频/周频选股因子？
4. 为什么同一因子在高频正向、在低频反转？如何避免逻辑错配？

---

## 2. 数据基础

| 数据 | 内容 | 沪深差异 | 用途 |
|---|---|---|---|
| Level2 快照 | 3 秒一次，十档买卖价量 | 基本一致 | 订单失衡、价差、斜率 |
| 逐笔成交 | 每笔成交价、量、买卖方向、叫买/叫卖序号 | 上交所/深交所字段有差异 | 大单、主买主卖、成交笔数 |
| 逐笔委托 | 每笔新增/撤单委托的价格、数量、时间戳 | 深交所 2012 起，上交所 2021.5 起 | 订单流、撤单、挂单记忆、LOB 还原 |

> 关键提醒：上交所与深交所的逐笔委托数据结构不同，市价单、订单撤回等细节处理不同；跨市场研究必须先统一口径（东方 76）。

## 3. 方法谱系

### 3.1 订单簿还原（LOB Reconstruction）
**代表**：海通《限价订单簿（LOB）的还原和应用》（P0274/P0313）

- 用逐笔委托 + 逐笔成交，按交易所撮合规则重建连续竞价阶段的盘口。
- 优势：更新频率可提升到 0.01 秒以内；避免快照丢失、快照间隔内的盘口变化。
- 用途：计算更精确的订单失衡、深度、价差、撤单率；为高频因子提供底层数据。
- 难点：撮合规则、撤单识别、集合竞价、市价单、隐藏单。

### 3.2 订单失衡（Order Imbalance）
**代表**：中信建投《高频量价选股因子初探》（P0056）、《多层次订单失衡及订单斜率因子》（P0055）

- **VOI（Volume Order Imbalance）**：委托买入量与委托卖出量之差。
- **OIR（Order Imbalance Ratio）**：买卖委托量之差除以总量，衡量不平衡程度。
- **OFI（Order Flow Imbalance）**：多层次（逐档）买卖价格/数量变化背后的订单影响。
- **MPB（Mid-Price Basis）**：按买方发起/卖方发起分类，用成交量和成交额推算平均成交价相对中间价的偏离。
- 关键实证：VOI/OIR 在高频上与收益正相关，但降为月频后与长期收益相关性反转；OFI 取绝对值后在月频为负向。**高频逻辑不能直接搬为低频因子**。
- 绩效示例：MPB 因子 IC 均值 -5.23%、年化 IR -2.68、年化多空 21.24%、夏普 2.68（中信建投 56）。

### 3.3 订单斜率与凸性（Order Book Slope / Convexity）
**代表**：中信建投 55、国金《斜率凸性因子》（P0184）

- **LogquoteSlope**：委托价对委托量变化的敏感性，衡量高频流动性/供需弹性。
- **斜率凸性**：订单簿斜率曲线的凸性，刻画"弹性"与"投资者耐心"。
- 逻辑：斜率越陡，流动性越差；凸性反映大单冲击下的价格弹性。
- 用法：日频聚合（均值/标准差/分位），正交化后选股。

### 3.4 订单流微观变迁
**代表**：开源《市场微观结构研究系列（21）订单流系列：关于市场微观结构变迁的故事》（P0213）、《（22）撤单行为规律初探》（P0214）、《（25）挂单方向长期记忆性的讨论与应用》（P0217）

- 订单流不只反映即时买卖压力，还包含市场结构变迁、撤单行为、挂单方向的长期记忆。
- 撤单行为：撤单率、撤单方向、撤单时机；可能反映做市/算法交易/虚假挂单。
- 挂单方向长期记忆：某方向挂单的持续性，可预测未来订单流方向。
- 这些因子适合与订单失衡、资金流因子组合使用。

### 3.5 逐笔委托 Alpha
**代表**：东方《基于委托订单数据的 alpha 因子》（P0042）

- 逐笔委托记录"何时、以什么价格、买卖多少、何时撤回"，理论上可重现整个交易过程。
- 可构造：委托规模分布、委托价格偏离、委托撤单率、委托方向持续性、委托时间聚集度。
- 注意：沪深数据覆盖差异（深交所更早、上交所 2021 后才完整），历史回测要处理覆盖率。

### 3.6 订单簿"温度"：成交笔数与帕累托
**代表**：东吴《"订单簿的温度"系列（一）反转因子的精细结构》（P0021）、《（二）逐笔成交中的帕累托因子》（P0022）

- **成交笔数**：撮合次数，从逐笔成交汇总。用平均单笔成交金额 D = 成交金额/成交笔数 对交易日排序，做 W 式切割：
  1. 回溯过去 N 个交易日（N 取偶数）；
  2. 按 D 从大到小排序，前 N/2 为高 D 组，后 N/2 为低 D 组；
  3. 分别加总两组日涨跌幅，得到 M_high、M_low；
  4. 用两者构造反转因子。
- 绩效：理想反转因子 IC -0.057、RankIC -0.070、多空年化 19.3%、信息比 2.51（正交后 2.97）。
- **帕累托因子**：逐笔委托量频率分布服从幂律衰减（小单多、大单少），用幂律参数/分布特征构造因子；剔除 Barra 后委买/委卖帕累托因子信息比 2.36/2.20。

### 3.7 订单流专著
**《订单流交易：了解微观市场结构并从中获利》**（Mike Valtos，P0075/P0385）

- 以期货市场为主，讲订单流（Order Flow）读盘方法：成交量分布、Delta、累积 Delta、吸收、失衡、POC/价值区。
- 与 A 股研报的差异：海外期货市场可看到更完整的订单流；A 股 Level2 数据受限，需用快照/逐笔近似。
- 可作为订单流直觉与交易执行的补充读物，不建议直接套用其参数。

## 4. 高频 → 低频的转换（关键）

订单簿因子的高频信号与低频选股逻辑经常不一致，必须做"逻辑一致性检验"：

| 因子 | 高频方向 | 低频方向 | 处理 |
|---|---|---|---|
| VOI/OIR | 与短期收益正相关 | 与长期收益负相关/反转 | 取绝对值、反转、或只用于高频择时 |
| OFI | 正向 | 绝对值后月频负向 | 用绝对值/波动类逻辑 |
| MPB | 负相关 | 负向选股 | 可直接降频 |
| 订单斜率 | 流动性溢价 | 需正交化 | 日频聚合+中性化 |
| 大单占比 | 正向 | 正向（需剔除异动） | 直接降频，控制异动股 |

**标准降频流程**：
1. 日内按分钟/快照计算因子序列；
2. 日频聚合（均值、标准差、分位、最大值、最小值、偏度）；
3. 对常规低频因子（市值、换手、反转、波动、行业）正交；
4. 月度/周度 IC、分层、多空测试；
5. 若方向反转，检查逻辑（短期冲击 vs 长期均值回复），不要盲目调参。

## 5. 实施流程

```
① 数据对齐
   - 快照/逐笔时间戳统一到交易所时钟
   - 处理集合竞价、午休、停牌、涨跌停
② 订单簿重建（可选）
   - 逐笔委托+成交 → 盘口序列
   - 校验：与官方快照对比
③ 因子构造
   - 失衡类：VOI/OIR/OFI（分档、分时段）
   - 斜率类：LogquoteSlope、凸性
   - 流类：撤单率、挂单记忆、订单流方向
   - 成交类：成交笔数、平均单笔金额、帕累托
④ 降频与清洗
   - 日频聚合 → 去极值 → 标准化 → 行业/市值中性化
⑤ 测试
   - IC/RankIC、分层、多空、换手、成本
   - 与高频/低频因子相关性矩阵
⑥ 组合
   - 与量价、资金流因子组合；控制换手与行业暴露
```

## 6. 常见陷阱

| 陷阱 | 说明 | 规避 |
|---|---|---|
| 快照间隔内的信息丢失 | 3 秒快照看不到期间撤单/成交 | 用逐笔重建 LOB |
| 沪深口径不一致 | 市价单、撤单、委托字段不同 | 分市场处理，统一后再合并 |
| 高频→低频逻辑反转 | VOI/OIR 典型 | 先做方向检验，再决定用法 |
| 盘口不可见/隐藏单 | 快照只显示十档 | 结合逐笔成交推断 |
| 集合竞价污染 | 集合竞价委托/成交结构不同 | 分开处理 |
| 交易成本被低估 | 高频因子换手高 | 双边成本+冲击成本+换手约束 |
| 幸存者偏差 | 退市/停牌股票被剔除 | 保留退市样本，按可交易性处理 |

## 8. 一页纸总结

- **订单簿因子的核心**：失衡（谁更急）、斜率（流动性/弹性）、流（撤单/挂单记忆）、成交结构（笔数/单笔金额）。
- **最稳的用法**：先在高频验证逻辑，再降频正交；不要假设高频方向在低频成立。
- **最值得先做的三个因子**：MPB（市价偏离）、订单斜率、成交笔数 W 式切割。
- **最需要的数据**：逐笔委托（上交所 2021.5 后完整）；没有逐笔委托时用快照+逐笔成交近似。
- **下一步**：与 `资金流与大单`、`高频量价因子` 两域组合使用。
