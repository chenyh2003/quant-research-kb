## 一、这套知识库怎么用

1. **先看知识树**：确定你的问题属于哪个知识域。
2. **读主题综述**：每个知识域有一篇 `_主题综述.md`，给出方法谱系、代表研报、实施流程与陷阱。
3. **查研报卡片**：`02_研报卡片/<机构>/` 下每篇研报一张卡，含摘要、原文结论段、指标摘录、目录、关键词与原文路径。
4. **找问题解法**：`03_问题解决方案库/问题索引.md` 按问题组织，每个问题给 2-5 种方案与取舍。
5. **用数据库检索**：`python 04_数据库/query.py "关键词"`；支持按主题、机构、系列、年份过滤。
6. **直接问问题**：`python 04_数据库/ask.py "你的问题"` 会自动匹配问题卡、候选方案与相关研报；加 `--save` 保存到 `06_输出/`。
7. **可视化选读**：双击 `08_可视化/index.html`，按标签/质量分筛选，收藏并导出阅读清单。
8. **看复现进展**：`09_复现/05_报告/复现报告_第一批.md`；网站“复现结果”页有表格与净值图。

## 二、知识树（三层结构）

### L0 量化研究总论
- 因子投资体系
- 研究流程与工程规范
- 统计推断与过拟合治理

### L1 数据与微观结构
1. **订单簿与订单流**：Level2 快照、逐笔成交、逐笔委托、订单失衡、订单斜率、撤单、挂单记忆
2. **市场微观结构理论**：价格发现、流动性、知情交易、交易行为、分层效应
3. **高频量价因子**：分钟/快照/逐笔数据构造的选股因子

### L2 因子族
4. **反转与动量**：W 式切割、交易者结构、信息分布、隔夜跳空、创新高、相同工作日动量
5. **换手率与流动性**：量稳换手、优加换手、分布均匀度、STR、流动性度量
6. **波动率与尾部风险**：已实现波动分解、信息分布均匀度、跳跃、振幅、波动率的波动率
7. **资金流与大单**：大单/小单、主买主卖、知情交易概率、聪明钱、羊群效应、资金流动力学
8. **文本舆情与另类数据**：新闻舆情、研报情感、BERT/HAN、文本 PEAD、FADT、新闻共同报道
9. **多因子框架与测试**：因子测试、正交化、中性化、缺失值/异常值、显著性、赋权、风险模型
10. **机器学习与AI选股**：GLM/SVM/树模型/集成/神经网络/GNN/GAN/遗传规划/强化学习/AutoML
11. **行业轮动与组合配置**：行业景气、行业动量、指数增强、组合优化、回撤控制
12. **CTA与期货策略**：遗传规划 CTA 信号、龙虎榜/成交量择时
13. **统计方法与过拟合**：时序交叉验证、Bootstrap 重采样、PBO、Newey-West
14. **因子投资理论综述**：外文经典、重尾分布、订单流专著、高频周期谱模型

## 五、推荐学习路径

### 路径 A：从零搭建多因子选股体系（8 步）
1. 多因子框架与测试 → 读 `东方证券-多因子量化投资体系手册`、光大因子测试三部曲
2. 数据预处理 → 财通拾穗（异常值、缺失值、财务前视、正交化、Newey-West）
3. 单因子测试 → 海通因子大讲坛、光大因子测试全集、东北多因子系列
4. 因子族 → 反转/动量、换手率、波动率、资金流
5. 因子合成与风险模型 → 国盛多因子系列、银河因子投资手册
6. 组合优化与指数增强 → 东北指数增强、华泰周频组合优化、申万回撤控制
7. 机器学习增强 → 华泰人工智能系列、海通深度学习高频因子
8. 过拟合治理 → 华泰时序交叉验证、Bootstrap、PBO

### 路径 B：高频因子研究（6 步）
1. 市场微观结构理论 → 开源微观结构系列（1-30）、兴业高频研究系列
2. 订单簿与订单流 → 中信建投订单失衡、海通 LOB 还原、东吴订单簿温度
3. 高频量价因子 → 海通高频因子系列、东吴技术分析系列、广发高频因子系列
4. 资金流与大单 → 海通买卖单/主买/大单系列、开源大小单资金流
5. 高频→低频 → 海通高频因子现实与幻想、高频数据低频化
6. 深度学习高频因子 → 海通 RNN/注意力/多颗粒度、华泰 AlphaNet

### 路径 C：因子挖掘与机器学习（6 步）
1. 华泰人工智能 1-10（框架与经典模型）
2. 华泰人工智能 11-18（集成、特征、损失函数、标签、调仓）
3. 华泰人工智能 19-30（过拟合、遗传规划、可解释、因果）
4. 华泰人工智能 31-63（GAN、AlphaNet、GNN、文本、强化学习）
5. 中信建投 AutoML/openFE/因子融合
6. 东方 DFQ 遗传规划/强化学习因子组合

## 七、使用约定

- **引用格式**：`[P0261] 海通证券《选股因子系列研究（五十六）——买卖单数据中的Alpha》`
- **卡片字段**：机构、日期、系列、主题、摘要、结论、指标、风险、目录、关键词、原文路径
- **重复组**：卡片若标记 `重复组: Gxxx`，优先读 `主记录`；副本仅保留溯源价值
- **数据边界**：本库只覆盖源文件夹内容；未包含桌面其他策略包与个人文件
