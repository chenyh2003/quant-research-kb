# 复现计划（Step-by-Step）

> **定位：验证性复现，不是策略开发。**
> 原则：先日频、再分钟、再逐笔；先单因子、再多因子、再组合；每一步只回答“研报结论是否成立/在什么条件下成立”，并以“复现成功/弱复现/失败/条件成立/无法验证”记录。
> 不做什么：不构建可实盘策略、不做组合优化、不评估容量/冲击成本/执行、不以收益为目标调参、不输出交易信号。

## 验证等级

| 等级 | 含义 | 状态 |
|---|---|---|
| **L1 初步简单验证** | 单一数据源、日频、单一股票池；无行业中性、无分钟/逐笔、无原始数据重建；只验方向/量级/基本稳健性 | ✅ 第一批 |
| **L2 完整复现** | 行业中性、参数网格、时序 CV/PBO、成本/分域、样本外 | 下一步 |
| **L3 全量验证** | 分钟/逐笔、原始数据重建、独立数据源、逐项核对公式/参数 | 后续 |

## L2 第二步：加行业中性 + 参数稳健性（下一步，目的是验证）

1. 用 `04_sw_classification/sw_stock_industry_history_csi1000.csv` 做行业中性化，比较 raw / size-neutral / industry+size-neutral；验证“研报 alpha 是否只是风格暴露”。
2. 对 Ret20/Turn20/STR20/CPV 做参数网格（10/20/40/60 日），记录 IC/IR；验证“20 日”是稳健选择还是样本内最优。
3. 用华泰 P0115/P0117 的时序 CV、P0124 的 PBO，检验研报结论的过拟合概率；不追求更高收益。
4. 输出 `复现报告_第二批.md`，结论只写“成立/条件成立/不成立/无法验证”。
