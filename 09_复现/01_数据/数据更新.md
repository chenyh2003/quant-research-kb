# 数据更新盘点（2026-11-10）

> 来源：仓库 `w.list()` 只读探测；当前 **82 个数据集**（上次盘点 62 个）。
> 只列对复现/验证有用的更新，不列纯海外/宏观边缘数据。
> 注意：仓库更新日期不等于 PIT；新增的 bulk 财务表 `available_time` 全部是 2026-10-27，属于“当前快照”，不是历史 vintage。

## 1. 结论先说

| 判断 | 内容 |

| **只是日期延长** | 日线/分钟/期货/期权 +2 个交易日；增量很小 |
| **仍然不能做** | 逐笔成交/逐笔委托/十档（P0）；2014-2022 历史分钟（P1）；历史指数成分（P1）；分析师/新闻正文/北向/基金持仓/融资融券个股 |

## 5. 新增数据能支持什么

### 5.1 PIT 财务验证（P0347）——现在可做
- 用 `a_share_balance_bulk` / `income_bulk` / `cashflow_bulk` 构造：ROE、毛利率、资产增长、营收/利润增长、应计、杠杆。
- 用 `a_share_disclosure.disclosure_date` 做公告日对齐，对比“报告期对齐 vs 公告日对齐”。
- 完整截面建议做到 **2026Q2**；2026Q3 只有 1,691 只，不能做全市场截面。
- **PIT 警告**：bulk 的 `vintage_date` / `available_time` 全部是 2026-10-27，不是历史 vintage；不能直接 `as_of()` 还原历史时点，只能用公告日做近似 PIT。

### 5.2 事件/情绪因子——现在可做
- 业绩快报/预告：超预期、预告类型、同比/环比。
- 股东户数：户数变化、户均持股变化（注意报告期与公告日）。
- 回购、大宗交易、公告索引：事件研究/公告类型计数。
- 公告索引只有标题，不是全文；文本因子仍缺正文。

### 5.3 宏观/商品/CTA——现在可做
- 中债收益率曲线（23 条）、人民币汇率、82 个商品期货主力连续。
- 适合做宏观状态划分、商品动量/期限结构、用户沪铜/沪金策略的日频验证。
- 仍无期货分钟/逐笔，不能做商品日内执行验证。

## 7. 建议下一步

1. **P1：PIT 财务验证（P0347）**——新 bulk 表 + 公告日，做 2014-2026Q2；这是本轮更新最直接可用的增量。
2. **P2：事件因子**——业绩快报/预告、股东户数、回购/大宗，先做单因子 IC/事件收益，不急着组合。
3. **L3 仍按原计划**：`minute_tq` 没延长，UTD 2024Q4 样本外仍可做（2024-09~12 已有）；逐笔类继续等 P0 数据。
4. **2026Q3 数据**：等披露完整后再做全市场截面；当前只适合做已披露样本。
