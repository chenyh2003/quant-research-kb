# 缺失数据清单（按验证优先级）

> 日期：2026-11-10
> 目的：把“现有数据做不了的研报验证”对应到具体数据项，便于采购/申请/补齐。
> 原则：只列验证必需字段；能少买就少买，先买 P0/P1。

---

## 一、P0：没有它就无法验证的研报方向

### P0-1 逐笔成交（Tick Trade）
| 项目 | 要求 |
|---|---|
| 必需字段 | 交易日、时间（毫秒）、证券代码、成交价、成交量、成交金额、BS 标志/主动买卖方向、叫买序号、叫卖序号、成交编号、交易所 |
| 频率/粒度 | 逐笔成交，毫秒/秒级时间戳 |
| 覆盖 | 全 A（沪深），至少 2014-2025；优先 2010-2025 |
| 用途 | W 式切割（成交笔数/平均单笔金额）、大单占比、主买/主卖、大单净买入、集中度、知情交易、订单流 |
| 对应研报 | P0021、P0261、P0263、P0264、P0268、P0272、P0277、P0203/P0207/P0209、P0043/P0044、P0246 |
| 验收标准 | 每日每股成交笔数/金额/BS 完整；逐笔成交量之和≈日线成交量（误差<0.5%）；时间戳与交易所一致 |
| 备注 | 没有逐笔成交，W 式切割/大单/主买只能做分钟近似，不能算复现 |

### P0-2 逐笔委托 + 十档盘口快照（Level2 / Order Book）
| 项目 | 要求 |
|---|---|
| 必需字段 | 交易日、时间（毫秒/3秒）、代码、十档买卖价/量、逐笔委托（新增/撤单、方向、价格、数量、订单号）、委托/撤单时间、交易所 |
| 频率/粒度 | 快照 3 秒（十档）+ 逐笔委托（毫秒） |
| 覆盖 | 全 A；上交所逐笔委托 2021.5 后才完整，深交所更早；优先 2021-2025 |
| 用途 | 订单失衡 VOI/OIR/OFI/SOIR、订单斜率/凸性、MPB/MPC、LOB 还原、撤单/挂单记忆、盘口流动性 |
| 对应研报 | P0055、P0056、P0057、P0274、P0042、P0184、P0213、P0214、P0217 |
| 验收标准 | 十档盘口完整；逐笔委托可重建盘口；重建盘口与官方快照误差小；沪深字段口径统一 |
| 备注 | 这是订单流/订单簿类研报的硬门槛，分钟线替代不了 |

## 六、优先级结论

1. **若只做“现有数据能做到的”**：不用买数据，继续 UTD 深度验证 + 日频扩展 + PIT 财务（仓库已有）。
2. **若要做逐笔/订单流**：必须补 **逐笔成交 + 逐笔委托/十档快照**，这是硬缺口。
3. **若要把分钟因子做到研报样本期**：补 **2014-2022 全 A 分钟线**。
4. **指数增强/分池测试**：补 **历史指数成分与权重**。

> 建议先确认目标：是继续“当前数据验证”，还是进入“逐笔/订单流”或“历史分钟复现”。不同目标对应完全不同的数据采购。
