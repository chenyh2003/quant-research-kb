# 组合权重换手成本与约束优化

> 日期：2026-11-10
> 数据：2014-2025 月度因子收益；滚动 36 个月；样本外 2017-2025。
> 问题：加入权重换手成本和换手上限后，优化能否跑赢等权？
> 定位：验证性复现，不是策略。

## 1. 结论

**权重层换手成本很小，加成本后结论不变：等权仍然最好。**

| 方式 | 毛年化/IR | 净 0.1% 年化/IR | 净 0.2% 年化/IR | 月权重换手 |
|---|---:|---:|---:|---:|
| 等权 | 13.9% / 3.28 | **13.9% / 3.28** | 13.9% / 3.28 | 0.0% |
| 逆波动 | 11.0% / 3.28 | 10.9% / 3.27 | 10.9% / 3.26 | 1.8% |
| 滚动最大夏普 | 11.9% / 3.05 | 11.8% / 3.02 | 11.7% / 3.00 | 8.7% |
| 最大夏普 + 10% 换手上限 | 12.1% / 3.10 | **12.0% / 3.08** | 11.9% / 3.06 | 6.8% |
| 最大夏普 + 20% 换手上限 | 12.0% / 3.05 | 11.8% / 3.02 | 11.7% / 3.00 | 8.6% |
| 最大夏普 + 30% 换手上限 | 11.9% / 3.05 | 11.8% / 3.02 | 11.7% / 3.00 | 8.7% |

- 权重层换手成本最多吃掉约 0.2pp/年，因为权重本身不常大幅变动；
- 10% 换手上限比无约束略好（净 IR 3.08 vs 3.02），但仍低于等权 3.28；
- 20%/30% 上限与无约束几乎一样，因为无约束换手只有 8.7%/月；
- 等权权重换手为 0，成本最低。

## 2. 2025

| 方式 | 毛年化/IR |
|---|---:|
| 等权 | 11.8% / 3.13 |
| 逆波动 | 10.3% / 3.12 |
| 滚动最大夏普 | 9.7% / 3.12 |
| 最大夏普 + 10% 上限 | 9.7% / 3.12 |

- 2025 所有优化方式 IR 都在 3.12 左右，等权 3.13 仍最高；
- 2025 只有 12 个月，权重换手成本影响很小。

## 3. 口径

- 权重：base / 隔夜 / 应计；
- 训练：滚动 36 个月；
- 协方差：样本协方差 + 20% 对角收缩；
- 约束：非负、和=1、单因子≤80%；换手上限为 `sum|w_t - w_{t-1}| ≤ cap`；
- 成本：`c × sum|w_t - w_{t-1}|`，c=0.1%/0.2% 单边；
- **只计权重层换手**，未计底层因子组合自身的换手；
- 网格步长 5%。

## 4. 判断

| 问题 | 结论 |
|---|---|
| 权重换手成本大吗？ | **不大**，最多约 0.2pp/年 |
| 加上限后优化能赢等权吗？ | **不能**，10% 上限净 IR 3.08 < 等权 3.28 |
| 换手上限有用吗？ | 10% 上限比无约束略好，但幅度很小 |
| 等权是否仍最稳？ | **是** |
| 能直接当策略吗？ | **不能**：只计权重成本，未计底层因子换手/冲击/容量 |

## 5. 限制

- 只计权重层换手，底层因子组合每月仍有 10%-70% 换手；
- 未做真正的组合优化器/风险模型；
- 3 个因子、36 个月窗口、固定收缩系数；
- 未计冲击成本、融券成本、行业/风格约束；
- 2025 样本短。
