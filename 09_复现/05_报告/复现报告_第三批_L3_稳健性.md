# L3 全 A 稳健性报告（2025，分钟派生因子）

> **定位：L3 稳健性验证，不是策略开发。**
> 在 2025 全 A 分钟派生因子上，做市值/行业中性、成本、bootstrap、大小盘分组、因子相关性。
>
> 日期：2026-11-10
> 样本：2025 全 A，月度约 3,051 只；12 个月
> 数据：`09_复现/01_数据/warehouse_full/`；代码：`run_l3_robust.py`
> 结果：`l3_robust_summary.csv`、`l3_robust_bootstrap.csv`、`l3_robust_size.csv`、`l3_corr.csv`

---

## 一、结论先行

| 因子 | 稳健性判断 | 关键证据 |
|---|---|---|
| UTD 换手分布均匀度 | **最稳** | 行业+市值中性后 LS 15.1%/IR 2.68；bootstrap p<0.001；大小盘都有效 |
| 高频偏度 | **中性后才成立，且仅小盘** | 中性后 LS 13.9%/IR 1.82；raw 近 0；小盘 LS 17.7%/IR 1.59，大盘 -11.9% |
| 下行波动占比 | **中性后才成立，且仅小盘** | 中性后 LS 11.1%/IR 1.34；小盘 20.9%/IR 2.14，大盘 -11.5% |
| CPV | **不稳健** | 中性后 LS -2.7%~-6.2%；bootstrap p 0.08-0.22；大小盘方向不一致 |
| RPV_B | **IC 显著但多空弱** | 中性后 IC -0.035、p 0.022；LS 3.8%/IR 0.79；仅小盘 |
| RPV_A | 与 RPV_B 完全负相关 | 仅为 RPV_B 镜像 |

## 四、大小盘分组（raw）

| 因子 | 小盘 IC | 大盘 IC | 小盘多空/IR | 大盘多空/IR |
|---|---:|---:|---:|---:|
| CPV | -0.067 | -0.009 | 5.9% / 0.72 | -15.6% / -1.14 |
| UTD | -0.086 | -0.077 | 16.9% / 2.43 | 9.1% / 0.87 |
| 偏度 | -0.115 | -0.042 | 17.7% / 1.59 | -11.9% / -0.78 |
| 下行 | 0.121 | 0.049 | 20.9% / 2.14 | -11.5% / -0.70 |
| RPV_B | -0.056 | -0.022 | 9.7% / 1.78 | -2.7% / -0.38 |

**解读**：
- UTD 大小盘都有效，小盘更强；这是它最稳的原因。
- 偏度/下行/RPV **仅小盘有效**；大盘方向相反/无效。
- CPV 大小盘方向相反，不能作为全市场因子。

## 五、因子相关性（月度截面 Spearman 平均）

| 因子对 | 平均相关 |
|---|---:|
| 高频偏度 vs 下行波动 | **-0.933** |
| UTD vs 高频偏度 | 0.492 |
| UTD vs 下行波动 | -0.449 |
| CPV vs 高频偏度 | 0.368 |
| CPV vs 下行波动 | -0.331 |
| CPV vs UTD | 0.227 |
| RPV_A vs RPV_B | -1.000 |

**解读**：
- **高频偏度与下行波动几乎是同一因子的正反面**（-0.933），不要同时加入组合。
- UTD 与它们中等相关（0.45-0.49），有一定独立性。
- CPV 与 UTD 相关性低（0.23），但 CPV 本身不稳健。

## 六、L3 稳健性结论

1. **UTD 是现有分钟数据下最值得继续验证的因子**：方向稳定、行业+市值中性后 LS 15.1%/IR 2.68、bootstrap p<0.001、大小盘都有效。
2. **偏度/下行波动**：中性后 IC 显著，但 raw 多空为 0、仅小盘有效、两者高度共线；只能作为“小盘条件因子”，不能当全市场因子。
3. **CPV**：2025 全 A 下不稳健（IC 不显著、多空为负、大小盘方向相反）；与研报 2014-2020 的强结果不一致，可能是时段/市场结构差异。
4. **RPV**：IC 显著但多空弱、仅小盘；只能算“方向性验证”，不足以支持研报的强多空。
5. **成本**：UTD 扣 0.1% 后仍 13.1%/IR 2.34；其他因子扣费后更弱。

---

## 七、边界

- 2025 单年、12 个月；不能覆盖研报 2014-2022 样本期。
- 行业映射用当前分类（非 PIT），仅作稳健性近似。
- 未做容量/冲击成本/执行；等权多空。
- 分钟数据仅 2024-09~2025-12；无逐笔/盘口。

---

## 八、一句话结论

**在 2025 全 A 分钟数据上，只有 UTD 通过了“行业+市值中性 + 成本 + bootstrap + 大小盘”四关；偏度/下行是仅小盘有效的共线因子；CPV/RPV 的 IC 方向对但多空不稳健。**
