# 应计定义深挖：现金流 vs 资产负债表 vs 单季

> 日期：2026-11-10
> 数据：2014-2025，144 个月；财务行 76,147 行、3,625 只。
> 问题：应计的结果是否依赖某一种定义？
> 定位：验证性复现，不是策略。

## 1. 结论

**核心结论是“现金流应计”最强，但不是所有定义都一样强。**

| 定义 | 行业+市值中性 | IC | IR | 2014-2019 | 2020-2025 |
|---|---:|---:|---:|---:|---:|
| 现金流应计/期末资产 | **7.9%** | 0.019 | **1.89** | 7.8% / 1.92 | 8.0% / 1.84 |
| 现金流应计/平均资产 | 7.8% | 0.019 | **1.92** | 7.5% / 1.93 | 8.0% / 1.89 |
| 资产负债表应计/平均资产 | 4.9% | 0.009 | 1.07 | 5.9% / 1.55 | 3.8% / 0.74 |
| 单季应计/平均资产 | 4.5% | 0.011 | 1.49 | 4.5% / 1.46 | 4.5% / 1.50 |

- 现金流应计两个版本几乎一样（相关 0.999），结论最稳；
- 资产负债表应计只有 4.9%/IR 1.07，且 2020-2025 衰减到 3.8%/0.74；
- 单季应计 4.5%/IR 1.49，稳定但弱于 TTM 现金流应计；
- 所有定义方向都是“低应计好”，没有方向反转。

**判断**：应计异象不是单一会计定义的伪影，但**强度依赖定义**；现金流/TTM 版本最可靠，资产负债表版本只能算弱证据。

## 2. 定义

| 名称 | 公式 |
|---|---|
| `acc_cf_end` | `(TTM归母净利润 - TTM经营现金流) / 期末总资产` |
| `acc_cf_avg` | `(TTM归母净利润 - TTM经营现金流) / 平均总资产` |
| `acc_bs` | `(Δ应收账款 + Δ存货 - Δ应付账款) / 平均总资产`（同比变化） |
| `acc_sq` | `(单季归母净利润 - 单季经营现金流) / 平均总资产` |

- 方向：全部按“低好”（做多低应计、做空高应计）；
- TTM：本期累计 + 上年年报 - 上年同期累计；
- 平均资产：期末与上年同期平均；
- PIT：按公告日 `disclosure_date` 对齐；
- 评价：月度 RankIC、五分组多空、行业+市值中性；未扣成本。

## 4. 子区间

| 定义 | 2014-2019 | 2020-2025 |
|---|---:|---:|
| 现金流/期末 | 7.8% / 1.92 | 8.0% / 1.84 |
| 现金流/平均 | 7.5% / 1.93 | 8.0% / 1.89 |
| 资产负债表 | 5.9% / 1.55 | 3.8% / 0.74 |
| 单季 | 4.5% / 1.46 | 4.5% / 1.50 |

- 现金流应计两段都稳；
- 资产负债表应计 2020 后明显衰减；
- 单季应计稳定但水平较低。

## 5. 相关性

|  | 现金流/期末 | 现金流/平均 | 资产负债表 | 单季 |
|---|---:|---:|---:|---:|
| 现金流/期末 | 1.000 | 0.999 | 0.491 | 0.486 |
| 现金流/平均 | 0.999 | 1.000 | 0.488 | 0.488 |
| 资产负债表 | 0.491 | 0.488 | 1.000 | 0.249 |
| 单季 | 0.486 | 0.488 | 0.249 | 1.000 |

- 现金流两个版本几乎完全一样；
- 资产负债表应计与现金流应计的相关只有 0.49；
- 单季与两者相关 0.25-0.49，信息差异较大。

## 6. 判断

| 问题 | 结论 |
|---|---|
| 应计是否依赖单一云端定义？ | 不是，四种定义方向都为正 |
| 哪个定义最强？ | **现金流/TTM**，7.8%-7.9%/IR 1.9 |
| 资产负债表应计能用吗？ | 弱，4.9%/1.07，且 2020 后衰减 |
| 单季应计能用吗？ | 4.5%/1.49，稳定但弱 |
| 应计是否会计伪影？ | **不是**，但强度依赖定义 |
| 能直接当策略吗？ | **不能**：未扣成本/容量，公告日近似 PIT |

## 7. 限制

- 资产负债表应计只用 AR/INV/AP，未覆盖全部营运资本科目；
- 金融企业资产负债表科目缺失，样本 3,625 只；
- 公告日近似 PIT，使用当前快照；
- 未扣成本/容量；
- 单季应计对季节性和负利润更敏感。
