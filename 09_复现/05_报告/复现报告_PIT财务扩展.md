# PIT 财务扩展报告：ROE / 资产增长 / 应计 / 杠杆

> 日期：2026-11-10
> 关联：P0347《水月镜花：正视财务数据的前向窥视问题》
> 数据：`a_share_income_bulk`、`a_share_balance_bulk`、`a_share_cashflow_bulk`、`a_share_disclosure`
> 定位：验证性复现，不是策略。

## 1. 结论

**P0347 的“前视偏差”不是所有财务因子的通病。**

| 因子 | 不修正（中性） | 公告日（中性） | 法定截止日（中性） | 判断 |
|---|---:|---:|---:|---|
| ROE(TTM) | 0.3% / 0.04 | -3.4% / -0.43 | -4.2% / -0.53 | 不成立 |
| 资产增长（低好） | 7.4% / 0.95 | **8.3% / 1.11** | **8.8% / 1.17** | **PIT 稳健，无虚高** |
| 应计（低好） | 7.4% / 1.58 | **8.3% / 1.98** | **7.9% / 1.83** | **PIT 稳健，无虚高** |
| 杠杆率（低好） | -7.0% / -1.16 | -6.6% / -1.13 | -6.6% / -1.13 | 方向相反，不成立 |

- **应计**：按公告日后仍有 8.3%/IR 1.98，2014-2019 与 2020-2025 都稳定；不修正没有抬高，反而略低。
- **资产增长**：公告日后 8.3%/IR 1.11，截止日后 8.8%/IR 1.17；同样没有前视虚高。
- **ROE**：公告日后 -3.4%，不成立。
- **杠杆率**：按“低杠杆好”的方向，结果为负；反向（高杠杆好）才为正，说明方向与先验相反，不能按常规质量因子解释。

这与前一份报告形成对照：
- 净利润/营收同比：不修正显著虚高，PIT 后归零；
- 应计/资产增长：PIT 后仍强，说明它们是**更可靠的财务异象**；
- 因此不能把 P0347 的结论外推到所有财务因子。

## 2. 数据与口径

- 样本：2014-01~2025-12，144 个月；月均 3,540 只；财务行 85,428 行、3,742 只。
- 财务数据：
  - 利润表：归母净利润；
  - 资产负债表：总资产、总负债、总权益；
  - 现金流量表：经营活动现金流净额；
  - 披露日期：`a_share_disclosure.disclosure_date`。
- 因子：
  - `roe_ttm = TTM归母净利润 / 总权益`；
  - `asset_growth = 总资产 / 上年同期总资产 - 1`；
  - `accruals = (TTM归母净利润 - TTM经营现金流) / 总资产`；
  - `leverage = 总负债 / 总资产`。
- TTM：本期累计 + 上年年报 - 上年同期累计。
- 方向：ROE 高好；资产增长、应计、杠杆按“低好”先验（方向 -1）。
- 评价：月度 RankIC、五分组等权多空、年化、IR、胜率、t 值；行业+市值中性；未扣成本。
- 方法：
  - A 不修正：报告期结束即用；
  - B 公告日：按实际披露日；
  - C 法定截止日：Q1 4/30、H1 8/31、Q3 10/31、年报次年 4/30，严格截止日之后；
  - D 真实修正：无法复现（仓库无历史 vintage）。

## 5. 判断

| 问题 | 结论 |
|---|---|
| P0347 的警告是否对所有财务因子成立？ | **否**；净利润/营收增长被虚高，但应计/资产增长没有 |
| 应计/资产增长是否 PIT 稳健？ | **是**，公告日后仍 8%+/年，IR 1-2 |
| ROE 是否成立？ | **否**，PIT 后为负 |
| 杠杆率是否成立？ | **方向相反**，按常规“低杠杆好”不成立 |
| 能否复现原文“真实修正”？ | **不能**，缺历史 vintage；但应计/资产增长在 B/C 都强，结论对 vintage 不敏感 |

**最重要的一条**：不要因为 P0347 说“财务数据有前视偏差”，就把所有财务因子都判死刑；应计、资产增长这类异象在公告日后依然存在，反而更干净。

## 6. 限制

- 总权益用 `TOTAL_EQUITY`，未用归母权益/平均权益；ROE 口径偏粗。
- 应计用 `(TTM净利润 - TTM经营现金流)/总资产`，未做资产负债表应计的细分。
- 未剔除金融/地产；行业中性用当前申万一级映射，非 PIT。
- 披露覆盖 3,742 只，低于全 A；小盘覆盖可能不足。
- 未扣交易成本；应计/资产增长换手不低，实盘需再扣。
- B/C 都使用当前快照，仍含事后修正；D 不可得。
