# 量化研报知识库（公开版）

个人研读笔记与研报索引的可视化站点。**不转载原始研报 PDF**；原文版权归原机构所有；仅供研究参考，不构成投资建议。

在线站点：https://chenyh2003.github.io/quant-research-kb/

## 内容

- 376 篇量化研报的标签化索引（主题/方向/数据/价值标签、质量分、摘要）
- 15 个知识域综述、24 个问题方案卡
- 18 篇深读/核验笔记（含对研报的批判性审视）
- 第一批 **L1 初步简单验证**（反转、换手、量稳换手、波动、CPV、振幅）的报告、结果与净值图

## 本地打开

直接双击 `index.html` 即可；或在本目录运行 `python -m http.server` 后访问本地端口。

## 更新

本站由本地知识库生成。维护者在本地更新后：

```bash
# 在本地知识库目录
python 08_可视化/build_site_data.py
python 08_可视化/build_public_site.py
# 然后把 public_site/ 的变更提交到本仓库
git add -A && git commit -m "update knowledge base" && git push
```

GitHub Pages 会自动重新部署。
