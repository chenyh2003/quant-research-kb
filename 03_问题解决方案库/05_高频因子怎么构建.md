# 问题 05：高频因子怎么从零构建

## 问题画像

- **症状**：有分钟/快照/逐笔数据，但不知道从哪下手；因子越做越多，增量越来越少；IC 高但组合不赚钱。
- **目标**：建立可复用的高频因子研究流程。
- **判断标准**：信息增量（正交后 IC）、稳定性、可实施性（数据/成本/换手）。

## 方案总览（按信息源）

| 方案 | 信息源 | 典型因子 | 数据要求 | 代表研报 |
|---|---|---|---|---|
| A. 收益率分布 | 分钟收益 | 已实现偏度、下行波动占比 | 分钟 | 海通 P0253/P0254 |
| B. 成交量分布 | 分钟成交量 | 分时占比、分布熵、量稳 | 分钟 | 光大 P0063/P0064、兴业 P0070 |
| C. 量价关系 | 分钟价+量 | CPV、RPV、量价背离 | 分钟/快照 | 东吴 P0023/P0035 |
| D. 资金流/大单 | 逐笔成交 | 大单占比、主买占比 | 逐笔 | 海通 P0261/P0263 |
| E. 订单簿/订单流 | 快照/逐笔委托 | 订单失衡、斜率、撤单 | L2 | 中信建投 P0055/P0056 |
| F. 事件/行为 | 分钟+逐笔 | 趋势资金、羊群、创新高 | 分钟/逐笔 | 国盛 P0160/P0156/P0162 |

## 通用构建流程（六步）

1. **选信息源**：先问"这个数据记录了什么行为？"（交易结果/订单意图/流动性）
2. **定义日频统计量**：均值、标准差、分位、偏度、相关系数、占比、事件计数
3. **确定窗口与频率**：回看 20/40/60 日；调仓日/周/月
4. **清洗**：去极值、标准化、行业/市值中性化
5. **测试**：IC/RankIC、分层、多空、换手、成本；对常规因子正交
6. **稳健性**：分年度/分股票池/参数敏感性/样本外

## 各方案要点

### A. 收益率分布
- 已实现偏度、峰度、上下行波动、下行波动占比。
- 结论：偏度、下行波动有效；单纯方差/峰度不显著（海通 P0253）。
- 改进：系统/特质分解（海通 P0254）。

### B. 成交量分布
- 集合竞价成交量占比（光大 P0063）；分时成交量 U 型（光大 P0064）。
- 分布熵、极大值、同价成交量（兴业 P0070）。
- 量稳换手（东吴 P0029）。

### C. 量价关系
- CPV/RPV（东吴）；量价背离（国金 P0183）；价量波动幅度（海通 P0298）。
- 最稳的一类，建议优先。

### D. 资金流/大单
- 大单占比、主买占比、集中度（海通 P0261/P0263）。
- 必须正交，避免成为流动性代理。

### E. 订单簿/订单流
- 订单失衡、斜率、MPB（中信建投 P0055/P0056）。
- 注意高频→低频方向反转。

### F. 事件/行为
- 趋势资金、羊群、创新高、遗憾恐惧（国盛/国金）。
- 事件稀疏，需长样本。

## 决策树

```
数据粒度？
├─ 分钟 → A/B/C
├─ 快照 → C/E
├─ 逐笔成交 → D/F
└─ 逐笔委托 → E/F
```

## 最小可行验证（1-2 天）

1. 选一类数据（建议分钟），构造 3 个因子：CPV、已实现偏度、分时成交量占比；
2. 统一清洗/中性化；
3. 计算 IC/分层/多空/换手；
4. 两两相关性与对常规因子正交；
5. 选出增量最高的 1 个，做分年度/样本外。
