# 问题 02：动量因子怎么构建与改进

## 问题画像

- **症状**：A 股中长期反转强、动量弱；传统 12-1 动量不赚钱；动量因子换手高、回撤大。
- **目标**：构建适合 A 股的动量因子，或把动量信息用于改进反转。
- **判断标准**：IC/RankIC、分层、多空、换手、分年度稳健性。

## 方案总览

| 方案 | 核心思路 | 适用条件 | 优点 | 风险/成本 | 代表研报 |
|---|---|---|---|---|---|
| A. 隔夜动量/MIF | 隔夜跳空 + 昨日换手率相关 | 日频数据 | 逻辑新颖、数据要求低 | 隔夜信息弱 | 国盛 P0151/P0152 |
| B. 交易者结构动量 | 大单/小单占比区分动量/反转 | 逐笔数据 | 逻辑清晰 | 数据要求高 | 国盛 P0153、东吴 P0025 |
| C. 创新高动量 | 锚定效应，创新高后超额 | 日频数据 | 事件清晰 | 胜率低、赔率高 | 国盛 P0162 |
| D. 相同工作日动量 | 特定工作日收益预测未来同日 | 日频数据 | 日历规律 | 容量/稳定性待验证 | 西南 P0329 |
| E. 时点动量 | 特殊时点领涨行业延续 | 行业/ETF 数据 | 可做行业轮动 | 时点定义主观 | 东方 P0046 |

## 方案 A：隔夜动量 / MIF

**原理**：传统隔夜因子只有微弱动量。对隔夜涨跌幅加绝对值，再与昨日换手率求相关，构造 MIF（Market Inefficiency Factor）。逻辑：隔夜大幅跳空 + 低换手 → 知情交易者信息优势 → 未来收益。

**步骤**：
1. 计算隔夜涨跌幅 = 今开/昨收 - 1；
2. 取绝对值；
3. 计算与昨日换手率的相关系数（滚动窗口）；
4. 构造 MIF 因子；
5. 测试/正交。

**绩效参考**：传统隔夜因子 IC 0.006、多空年化 2.27%、IR 0.26、回撤 >30%；MIF 显著改进（国盛 P0151）。

**优点**：数据要求低；逻辑新颖。
**风险**：隔夜信息噪声大；参数窗口敏感。
**验证**：与反转/换手正交后的增量。

**代表研报**：P0151/P0152 国盛。

## 方案 B：交易者结构动量

**原理**：不同交易者结构下，涨跌幅因子呈现动量或反转。大单占比高 → 反转强；小单占比高 → 动量/反转不同。

**步骤**：
1. 划分大单/小单；
2. 计算占比；
3. 分组/加权构造动量因子；
4. 测试。

**优点**：可与反转研究共用数据。
**风险**：大单对倒；阈值敏感。
**验证**：分股票池/分市值。

**代表研报**：P0153 国盛；P0025 东吴。

## 方案 C：创新高动量

**原理**：锚定效应下，股价接近前高时投资者认为难突破，导致反应不足；创新高后继续上涨。中证 800 创新高后 240 日平均超额 6.37%。

**步骤**：
1. 定义创新高（收盘价 > 过去 N 日最高）；
2. 事件后持有固定期限；
3. 构造事件因子/组合；
4. 控制行业/市值。

**优点**：事件清晰；逻辑强。
**风险**：胜率低、赔率高；事件稀疏。
**验证**：不同 N、不同持有期；分市场状态。

**代表研报**：P0162 国盛《创新高股票中的 Alpha》。

## 方案 D：相同工作日动量

**原理**：过去某个特定工作日的收益率之和，正向预测同一工作日的未来收益率。机构在每周特定工作日的交易行为可能是来源。

**步骤**：
1. 按工作日分组（周一至周五）；
2. 计算每个工作日的历史收益之和；
3. 构造相同工作日动量因子；
4. 分组测试。

**绩效参考**：2012/01-2024/06，分组收益单调；考虑交易费用后测试持仓策略（西南 P0329）。

**优点**：数据要求低；日历规律。
**风险**：容量有限；可能被交易成本吞噬。
**验证**：分年度、扣费后。

**代表研报**：P0329 西南《相同工作日动量因子》。

## 方案 E：时点动量（行业层面）

**原理**：市场在特殊时点存在"引爆点"式动量：下跌反弹、顶部切换、横盘突破、北向异常流入、宏观指标披露。这些时点领涨的行业/ETF 未来有延续性。

**步骤**：
1. 定义五类时点；
2. 识别时点领涨行业；
3. 构造行业轮动策略；
4. 回测。

**优点**：适合行业/ETF 轮动。
**风险**：时点定义主观；过拟合。
**验证**：样本外、参数敏感性。

**代表研报**：P0046 东方《基于时点动量的因子轮动》。

## 决策树

```
做个股还是行业？
├─ 个股 → 有逐笔数据？
│  ├─ 是 → B（交易者结构）
│  └─ 否 → A（隔夜 MIF）或 C（创新高）
└─ 行业/ETF → E（时点动量）
```

## 最小可行验证

1. 复现隔夜因子与 MIF，对比 IC/多空；
2. 复现创新高事件，统计 20/60/120/240 日超额；
3. 对反转/换手正交，看增量；
4. 分 2015 前后看稳健性。
