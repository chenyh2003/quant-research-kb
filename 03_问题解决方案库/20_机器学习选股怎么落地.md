# 问题 20：机器学习选股怎么落地

## 问题画像

- **症状**：想上机器学习但不知道选什么模型；回测过拟合；特征/标签不会设计；模型黑箱无法解释。
- **目标**：建立可落地、可验证的机器学习选股流程。
- **判断标准**：样本外 IC/超额、稳定性、换手/成本、可解释性、可复现。

## 方案总览

| 阶段 | 推荐方案 | 备选 | 代表研报 |
|---|---|---|---|
| 模型 | XGBoost/随机森林 | 线性/神经网络 | 华泰 P0136/P0137 |
| 标签 | 收益率/分类 | IR/Calmar/有序回归 | 华泰 P0118/P0131/P0106 |
| 特征 | 量价+基本面+高频 | 文本/图关系 | 华泰 P0113 |
| 防过拟合 | 时序 CV + PBO | Bootstrap/随机种子 | 华泰 P0115/P0124 |
| 组合 | 组合优化控换手 | 打分法 | 华泰 P0119/P0085 |
| 解释 | SHAP/LIME | 特征重要性 | 华泰 P0129 |

## 落地流程（八步）

```
① 明确目标：预测收益/排序/分类；调仓频率
② 数据：point-in-time；训练/验证/测试按时间切分
③ 特征：量价/基本面/高频/文本；缺失值/异常值/中性化
④ 标签：收益率/分类/IR/Calmar/有序回归
⑤ 模型：先线性/树模型，再神经网络；时序 CV
⑥ 评估：IC/RankIC、分层、多空、扣成本
⑦ 稳健性：多种子、参数敏感性、PBO、样本外
⑧ 组合：风险约束、换手约束、可解释性
```

## 关键经验

1. **先简单后复杂**：线性/树模型往往够用；神经网络收益不一定更大。
2. **标签比模型重要**：另类标签/有序回归可显著提升（华泰 P0131/P0106）。
3. **时序 CV 是底线**：传统 K 折会泄漏（华泰 P0115）。
4. **周频优于月频**，但需组合优化控换手（华泰 P0119）。
5. **随机种子必须报告**（华泰 P0122）。
6. **可解释性是资管刚需**：SHAP/LIME/因果推断（华泰 P0129/P0133）。

## 模型选择建议

| 数据量 | 推荐 |
|---|---|
| 小（<5 年） | 线性/岭回归/逻辑回归 |
| 中（5-10 年） | XGBoost/随机森林 |
| 大（>10 年，高频） | 神经网络/RNN/CNN |
| 图关系 | GNN |
| 序列生成 | GAN/WGAN（谨慎） |

## 常见陷阱

1. 数据泄漏（全样本标准化/未来数据）。
2. 传统 K 折 CV。
3. 只报最优随机种子。
4. 过拟合回测（PBO 高）。
5. 忽略交易成本/换手。
6. 黑箱不可解释。

## 最小可行验证

1. 用 XGBoost + 20 个量价因子，月频选股；
2. 时序 CV 选参；
3. 对比线性基准；
4. 扣成本；
5. 样本外 2 年。
