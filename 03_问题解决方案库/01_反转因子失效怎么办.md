# 问题 01：反转因子失效/不稳定怎么办

## 问题画像

- **症状**：20 日反转因子分组不单调、多空回撤大、某些年份失效；剥离流动性/波动率后超额接近 0。
- **目标**：提升反转因子的稳定性、单调性、增量信息。
- **判断标准**：IC/RankIC、ICIR、分层单调性、多空夏普、最大回撤、对 Barra 风格正交后的增量。

## 方案总览

| 方案 | 核心思路 | 适用条件 | 优点 | 风险/成本 | 代表研报 |
|---|---|---|---|---|---|
| A. W 式切割 | 按平均单笔成交金额切分交易日 | 有逐笔成交数据 | 简单、可解释、绩效强 | 需要逐笔数据 | 东吴 P0021 |
| B. 交易者结构切割 | 按大单/小单占比切分 | 有逐笔/大单数据 | 逻辑清晰 | 数据要求高 | 东吴 P0025/P0031 |
| C. 信息分布切割 | 按反应不足/过度识别状态 | 有量价数据 | 直击本质 | 状态判定复杂 | 东吴 P0033/P0038 |
| D. 隔夜/日内拆分 | 分别构造隔夜、日内反转 | 有日频数据 | 数据要求低 | 隔夜信息弱 | 国盛 P0151、东吴 RPV |
| E. 动量/反转状态识别 | 先把动量股剔除/单独处理 | 有量价数据 | 提升反转纯度 | 状态误判风险 | 方正 P0239、国信 P0154 |

## 方案 A：W 式切割（首选）

**原理**：平均单笔成交金额 D = 当日成交金额 / 当日成交笔数。高 D 日更可能是大资金主导，低 D 日更可能是散户主导；两组收益的信息含义不同，分别加总可提纯反转信号。

**步骤**：
1. 每月底回溯过去 N 个交易日（N 取偶数，常用 20）；
2. 逐日计算 D，按 D 从大到小排序；
3. 前 N/2 为高 D 组，后 N/2 为低 D 组；
4. 分别加总两组日涨跌幅，得到 M_high、M_low；
5. 用 M_high、M_low 构造反转因子（具体组合方式见原文）；
6. 去极值、标准化、行业/市值中性化；
7. IC/分层/多空测试，对 Barra 风格正交。

**参数**：N=20；股票池全 A（剔除 ST、上市未满 60 日）；月度调仓。

**绩效参考**：理想反转因子 IC -0.057、RankIC -0.070、多空年化 19.3%、信息比 2.51（正交后 2.97）（东吴 P0021）。

**优点**：仅需逐笔成交汇总的成交笔数/金额；逻辑直观；改进幅度大。
**风险**：逐笔数据质量；N 的敏感性；高换手成本。
**验证**：与原始 20 日反转相关性；正交后 IC；分年度稳健性；换手/成本。

**代表研报**：P0021 东吴《订单簿的温度（一）：反转因子的精细结构》。

## 方案 B：交易者结构切割

**原理**：按挂单金额把交易者分为机构、大户、中户、散户；大单占比越高、小单占比越低，反转效应越强。用小单占比提取信息，构造"聪明版"反转。

**步骤**：
1. 按挂单金额划分交易者类型；
2. 计算每日/每月大单、小单成交占比；
3. 用占比对涨跌幅因子加权/切割；
4. 构造反转因子并测试。

**参数**：交易者划分阈值按市场/股票调整；A 股中户+散户占比 >70%。

**优点**：逻辑清晰；可与 W 式切割结合。
**风险**：大单可能是对倒/游资；阈值敏感。
**验证**：与 W 式切割因子的相关性；分股票池。

**代表研报**：P0025 东吴《交易者结构对动量因子的改进》；P0031 Q&A。

## 方案 C：信息分布切割

**原理**：动量/反转的本质是股价对信息的反应程度。反应不足 → 动量，反应过度 → 反转。用成交量/信息流特征识别状态。

**步骤**：
1. 构造信息分布指标（成交量、换手、信息流速度）；
2. 识别反应不足/过度状态；
3. 在不同状态下分别使用动量/反转；
4. 测试。

**优点**：直击本质；可解释。
**风险**：状态判定主观；参数多。
**验证**：状态划分的样本外稳定性。

**代表研报**：P0033/P0038 东吴《反应不足 or 反应过度》。

## 方案 D：隔夜/日内拆分

**原理**：隔夜收益更多反映知情交易/机构，日内收益更多反映散户/流动性；两者方向可能不同。

**步骤**：
1. 把日收益拆成隔夜（今开/昨收-1）与日内（收盘/今开-1）；
2. 分别构造反转/动量；
3. 用相关系数/条件收益组合。

**优点**：数据要求低；可与 RPV 结合。
**风险**：隔夜因子单独较弱（国盛 P0151：IC 0.006、多空 2.27%）。
**验证**：隔夜/日内分别 IC；组合后增量。

**代表研报**：P0151 国盛《隔夜涨跌变选股因子》；P0035 东吴 RPV。

## 方案 E：动量/反转状态识别

**原理**：部分股票月度呈现动量，削弱传统反转。先识别动量股，剔除或单独处理。

**步骤**：
1. 构造个股动量状态指标；
2. 把股票分为动量组/反转组；
3. 反转组合只保留反转组；
4. 测试。

**优点**：提升反转纯度。
**风险**：状态误判；分组后样本减少。
**验证**：分组收益；状态持续性。

**代表研报**：P0239 方正《球队硬币因子》；P0154 国信《反转因子全解析》。

## 决策树

```
有逐笔成交数据？
├─ 是 → 先做 A（W 式切割）；若增量不足，叠加 B/C
└─ 否 → 有日频数据？
   ├─ 是 → 先做 D（隔夜/日内拆分）；再做 E（状态识别）
   └─ 否 → 先补数据
```

## 最小可行验证（1 天）

1. 取全 A 20 日反转因子，计算 IC/分层/多空；
2. 实现 W 式切割（N=20），对比 IC、多空夏普、换手；
3. 对 Barra 市值/换手/波动正交，看增量；
4. 分 2010-2015/2016-2020/2021-2025 三段看稳健性。
