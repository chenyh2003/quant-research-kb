# 问题 23：因子拥挤/失效怎么办

## 问题画像

- **症状**：因子 IC 逐年下降；多空回撤扩大；同类因子大量出现；不知道是暂时回撤还是永久失效。
- **目标**：诊断失效原因，选择应对方案。
- **判断标准**：IC 时序、拥挤度指标、因子相关性、基本面逻辑是否仍成立。

## 方案总览

| 方案 | 核心思路 | 优点 | 风险 | 代表研报 |
|---|---|---|---|---|
| A. 诊断失效原因 | 区分拥挤/结构变化/逻辑失效 | 对症下药 | 需要数据 | 开源 P0218 |
| B. 因子改进/切割 | 用新维度切分旧因子 | 延续因子生命 | 过拟合 | 开源 P0201 |
| C. 多因子分散 | 多逻辑/多频率组合 | 降低单一因子风险 | 收益摊薄 | 通用 |
| D. 因子择时/降权 | 动态调整权重 | 控制回撤 | 择时风险 | 海通 P0290 |
| E. 寻找新数据源 | 高频/文本/另类数据 | 增量 | 成本 | 华泰/海通 |

## 方案详情（压缩）

### A. 诊断
- 开源 P0218：资金流与交易行为，因子失效的原因与讨论。
- 可能原因：拥挤、市场结构变化、交易者行为变化、数据口径变化、逻辑失效。
- 工具：IC 时序、因子相关性、换手、拥挤度。

### B. 改进/切割
- 开源 P0201：因子切割论，用新维度切分旧因子。
- 例子：反转按单笔金额切割（W 式）、振幅按时段切割。
- 风险：过度切割/过拟合。

### C. 多因子分散
- 多逻辑（反转/动量/资金流/基本面）、多频率（日/周/月）、多数据源。
- 降低单一因子失效的冲击。

### D. 择时/降权
- 海通 P0290：条件期望因子择时。
- 风险：择时本身可能失效；建议温和降权而非全切。

### E. 新数据源
- 高频（订单簿/逐笔）、文本（新闻/研报）、另类（卫星/招聘/供应链）。
- 增量来源，但成本/合规。

## 诊断清单

```
□ IC 是逐年下降还是突然失效？
□ 多空回撤是否伴随换手/拥挤度上升？
□ 与同类因子相关性是否上升？
□ 基本面/行为逻辑是否仍成立？
□ 数据口径/市场结构是否变化？
□ 是否只是风格暴露（市值/波动）？
```

## 决策树

```
逻辑仍成立？
├─ 是 → B（切割/改进）或 D（降权）
└─ 否 → E（新数据源）或放弃
```

## 最小可行验证

1. 画出因子 IC/多空 5 年时序；
2. 计算与同类因子相关性；
3. 用切割论做 1-2 个改进版本；
4. 对比改进前后样本外。
