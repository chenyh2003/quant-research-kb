# 问题 15：怎么检验过拟合

## 问题画像

- **症状**：回测很好但实盘失效；参数寻优后绩效"跳变"；不同随机种子结果差异大；不知道"最优模型"是否只是噪声。
- **目标**：建立过拟合检验流程，给出可信度评估。
- **判断标准**：时序 CV、样本外、参数敏感性、Bootstrap/PBO、随机种子分布。

## 方案总览

| 方案 | 核心方法 | 优点 | 风险 | 代表研报 |
|---|---|---|---|---|
| A. 时序交叉验证 | 滚动训练/验证 | 防时序泄漏 | 计算量大 | 华泰 P0115/P0117 |
| B. Bootstrap 重采样 | 有放回抽样构造平行世界 | 直观 | 计算量 | 华泰 P0120 |
| C. PBO（CSCV） | 计算回测过拟合概率 | 量化风险 | 实现复杂 | 华泰 P0124 |
| D. 随机种子分布 | 多种子重复 | 检测不稳定 | 计算量 | 华泰 P0122 |
| E. 参数敏感性 | 参数网格/平原 | 简单 | 维度灾难 | 华泰 P0009、通用 |

## 方案详情（压缩）

### A. 时序 CV
- 训练集在前、验证集在后，滚动切分。
- 华泰 P0115：传统 K 折对时序数据过拟合；时序 CV 测试集更好。
- 华泰 P0117：改进基线模型与精确切分。

### B. Bootstrap
- 对样本内/样本外/回测时间有放回重采样。
- 若结论在平行世界复现，过拟合概率低（华泰 P0120）。

### C. PBO
- CSCV 框架：切子区间、组合训练/测试、计算最优策略的样本外排名。
- 华泰 P0124：多因子选股 PBO 15%-50%；择时模型较高。

### D. 随机种子
- 逻辑回归不敏感；全连接网络敏感；XGBoost/随机森林居中（华泰 P0122）。
- 报告多种子均值/方差/最差。

### E. 参数敏感性
- 参数平原优于尖峰；文本 FADT 参数不敏感 → 过拟合概率低（华泰 P0009）。

## 研究验收清单

```
□ 数据 point-in-time，无幸存者偏差
□ 训练/验证/测试按时间切分
□ 预处理只在训练集拟合
□ 时序 CV 选超参
□ 扣成本/换手约束
□ 多种子
□ 参数敏感性
□ 分年度/分股票池
□ Bootstrap/重采样
□ PBO
□ Newey-West t 值
□ 最终样本外（最近 1-3 年）
```

## 决策树

```
有时间做完整检验？
├─ 是 → A + C + D + E
└─ 否 → A + E（最低要求）
```

## 最小可行验证

1. 把样本切成 3 段：训练/验证/测试；
2. 时序 CV 选参；
3. 测试集只跑一次；
4. 参数扰动 ±20%，看绩效是否跳变。
