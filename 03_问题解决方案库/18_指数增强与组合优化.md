# 问题 18：指数增强/组合优化怎么做

## 问题画像

- **症状**：因子有效但组合跟踪误差大；行业/市值暴露失控；换手过高；回撤大。
- **目标**：构建风险可控的指数增强组合。
- **判断标准**：超额收益、跟踪误差、信息比、最大回撤、换手/成本、行业/市值偏离。

## 方案总览

| 方案 | 核心思路 | 优点 | 风险 | 代表研报 |
|---|---|---|---|---|
| A. 打分法 | 因子加权打分选股 | 简单 | 风险暴露失控 | 通用 |
| B. 组合优化 | 最大化收益-风险，约束暴露 | 风险可控 | 协方差估计 | 东北 P0015、华泰 P0085 |
| C. 分层抽样 | 行业内选股/分层配权 | 控制行业 | 个股选择弱 | 通用 |
| D. 空头剔除增强 | 剔除高频因子空头组 | 利用空头信息 | 实施复杂 | 海通 P0306 |
| E. 神经网络组合优化 | 端到端学习权重 | 灵活 | 黑箱/过拟合 | 华泰 P0098 |

## 方案详情（压缩）

### A. 打分法
- 因子标准化后加权打分，选前 N 只。
- 风险：行业/市值暴露不可控；需事后约束。

### B. 组合优化
- 目标：max 预期收益 - λ×风险；约束：行业偏离、个股权重、换手、跟踪误差。
- 东北 P0015：因子检验/合成/组合优化全流程。
- 华泰 P0085：周频 AlphaNet 的组合优化。

### C. 分层抽样
- 行业内按因子排序选股；行业权重匹配基准。
- 控制行业暴露；个股 alpha 较弱。

### D. 空头剔除
- 海通 P0306：事前/事后剔除高频因子空头组；事后更稳健。
- 适合有强空头效应因子的场景。

### E. 神经网络组合优化
- 华泰 P0098：LSTM 等端到端学习权重。
- 风险：黑箱、过拟合；需强约束。

## 关键经验

1. **组合优化的核心是风险模型**：行业/市值/风格暴露要可控。
2. **换手约束必不可少**：周频模型换手高（华泰 P0119）。
3. **空头剔除可提升指数增强**（海通 P0306）。
4. **简单打分 + 约束**往往优于复杂优化。

## 决策树

```
有风险模型？
├─ 是 → B（组合优化）
└─ 否 → A（打分）+ 行业/市值约束
```

## 最小可行验证

1. 用 3-5 个因子打分，构建沪深 300 增强；
2. 加行业/市值约束；
3. 对比跟踪误差/超额/换手；
4. 扣成本。
