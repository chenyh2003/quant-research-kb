# 问题 24：组合回撤怎么控制

## 问题画像

- **症状**：组合回撤大/恢复慢；极端行情下风控失效；止损后反弹踏空；不知道该事前还是事后控制。
- **目标**：在不过度牺牲收益的前提下控制回撤。
- **判断标准**：最大回撤、Calmar、恢复时间、换手、样本外。

## 方案总览

| 方案 | 核心思路 | 优点 | 风险 | 代表研报 |
|---|---|---|---|---|
| A. 风险预算 | 事前分配风险预算 | 稳健 | 参数 | 通用 |
| B. 波动率目标 | 按波动率调整仓位 | 简单 | 波动率估计 | 通用 |
| C. 回撤约束优化 | 把回撤作为优化约束 | 直接 | 实施复杂 | 申万 P0327 |
| D. 止损/止盈 | 事后触发 | 直观 | 滞后/踏空 | 通用 |
| E. 多因子分散 | 降低单一因子暴露 | 稳健 | 收益摊薄 | 通用 |
| F. 对冲 | 股指期货/期权对冲 | 直接 | 成本/基差 | 通用 |

## 方案详情（压缩）

### A. 风险预算
- 按因子/行业/个股分配风险预算；控制集中度。
- 优点：事前；缺点：需要风险模型。

### B. 波动率目标
- 目标波动率 / 实际波动率 → 仓位调整。
- 简单有效；波动率估计滞后。

### C. 回撤约束优化
- 申万 P0327：在组合优化中加入回撤控制机制。
- 优点：直接；缺点：回撤路径依赖、优化复杂。

### D. 止损/止盈
- 事后触发；容易滞后/踏空。
- 建议：结合波动率/ATR，而非固定百分比。

### E. 多因子分散
- 多逻辑/多频率/多因子；降低单一因子失效冲击。

### F. 对冲
- 股指期货/期权对冲系统性风险；成本/基差/展期。

## 关键经验

1. **回撤控制应事前（风险预算/约束）而非事后（止损）**。
2. **波动率目标是性价比最高的方案**。
3. **多因子分散是最稳的方案**。
4. **止损要结合波动率/ATR，固定百分比容易失效**。

## 决策树

```
能事前控制？
├─ 是 → A（风险预算）+ B（波动率目标）
└─ 否 → D（止损）+ E（分散）
极端风险 → F（对冲）
```

## 最小可行验证

1. 对现有组合加波动率目标，对比回撤/收益；
2. 加行业/个股集中度约束；
3. 对比有无止损；
4. 样本外。
